# PPT 课件生成 · 提升方案

> 云端智囊六功能之一。功能级方案见本文；**视觉/母版深挖见 `ppt-master-design-plan.md`（子文档，含测试分层）**。

## 0. 一句话定位
差异化（深空主题）已立住，缺的是"生成体验 + 导出即用 + 模板可用性"。最大痛点 = 视觉"二十几年前的 Office 默认模板感"（非花哨，是**工艺失败**），根源在字体、配色、版式三处被规则拉平。

## 1. 现状
- 深空主题差异化已做出来（视觉最出挑）。
- `lib/slides/agent/` 四段式管线：规划 → 章节 → 页面设计 → QA；QA 重试 3 次。
- PPTX 导出（`packages/pptxgenjs`）+ 课件库 RAG 参考 + 个性化（主题/难度/节奏/风格）。
- 云智囊入口只是传 `initialTopic` + 个性化上下文 + 提示条。

## 2. 短板与取舍
| # | 短板 | 取舍 |
|---|---|---|
| P1 | 四段式顺序依赖，一次跑完 10 页等待久 | 先出大纲+第一页，其余逐页追加显示（"先看到在干活"）；投入高（动管线切割），排期评估 |
| P2 | 导出公式走图片嵌入，跨设备糊、缺字体破版 | 公式转 MathML/OMML 原生嵌入（`packages/mathml2omml` 已封装）+ 字体降级 |
| P2 | 模板单一（基本一套深空主题） | 学术/科技/手绘多套 + 自定义 + 预览；详见子文档 |
| 核心 | 视觉"雅黑+天空蓝+卡片盒"老模板感 | **现代学术母版**（子文档核心）：思源黑体全替换 + 现代学术配色盘 + 6 套内页母版 + 双端渲染统一 |

## 3. 优先级行动
| 优先级 | 事项 |
|---|---|
| P0 | 默认设计语言重塑 → "现代学术"母版（见子文档，先做一套试点） |
| P0 | 双端渲染统一（预览与 PPTX 导出共用同一母版源，避免"预览好看导出破版"） |
| P1 | 逐页流式/分批生成（性能基线第 2 条） |
| P2 | 公式原生嵌入（MathML/OMML）|
| P2 | 多套主题扩展（"现代学术"试点通过后评估"暖现代"等）|

## 4. 测试方法
见 `ppt-master-design-plan.md` 第 3 节，四层：
- **3.1 样式不变量（自动）**：无雅黑/宋体/楷体/仿宋；标题≥36pt、正文≥24pt、任何文本≥18pt；每页 ≤3 色角色且强调色为盘内指定；列表≤4 项、标题≤2 行；留白≥1/3。
- **3.2 视觉审美（人工 A/B）**：改造前后同课程对比，≥7/10 通过；双端渲染逐页一致。
- **3.3 内容健壮性（自动）**：文/理（含公式）/应用 三科 8-10 页冒烟；长内容自适应不破版；公式（MathML/OMML）不破坏版式。
- **3.4 回归（自动）**：QA 重试、缓存、个性化注入不回归；导出可打开、无缺字体告警。
