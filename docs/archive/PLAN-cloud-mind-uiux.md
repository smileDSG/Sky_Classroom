# Cloud Mind UI/UX 统一主题改造方案

## 一、现状分析

### 1.1 Slides 页面（参考标杆）
Slides 页面采用了独特的 **"深空工坊 / Celestial Atelier"** 暗黑沉浸式主题：

| 设计维度 | 具体实现 |
|---------|---------|
| **背景** | 深空渐变 `#0B1021 → #1A1F3A`，搭配 `CelestialCanvas` 星空粒子（恒星+星云+网格+地平线辉光） |
| **文字** | 暖色星光 `#F5E6C8`，层级通过透明度区分（100%/60%/40%/20%） |
| **主色** | 黎明橙 `#FF8C69`、星云紫 `#8B5CF6`、天顶蓝 `#38BDF8` |
| **输入框** | 极简底部线条 + 聚焦辉光扩散动画 |
| **按钮** | 透明底 + 边框 + 扫光悬停效果 |
| **选择器** | "观测台" 风格 — 圆点轨道 + 脉冲光环 |
| **动效** | 星空视差、脉冲星、星云漂移、扫描线、地平线辉光 |
| **布局** | 全屏沉浸，无标准 AppShell |

### 1.2 其它页面（当前状态）
Quiz / Write / Translate / Memory / Solve / Teaching 全部使用标准 `SkyAppShell`：

| 设计维度 | 具体实现 |
|---------|---------|
| **背景** | 浅色水彩渐变（白/淡蓝/淡紫），暗色模式为深蓝 |
| **Hero 横幅** | 圆角渐变色块（每页不同色），白色文字 |
| **卡片** | `bg-white/70 backdrop-blur border` 毛玻璃卡片 |
| **按钮** | 渐变色实心按钮 + 阴影 |
| **布局** | 标准内容区 `max-w-6xl`，面包屑导航 |
| **问题** | 视觉上与 Slides 割裂感强，缺乏统一的沉浸感 |

---

## 二、设计目标

1. **主题统一** — 所有 cloud-mind 页面共享"深空"暗黑主题体系
2. **差异化设计** — 每个页面在统一主题下有不同的布局/交互特色
3. **功能不变** — 所有业务逻辑、API 调用、状态管理完全保留
4. **渐进改造** — 先做一个 demo 页面验证效果，再推广到其它页面

## 四、Demo 方案 — Quiz 页面 "星际试炼场"

### 4.1 选择 Quiz 页面的理由
- 功能完整，状态多（idle/generating/answering/done），适合验证复杂场景
- 有明确的进度/答题/结果展示流程，动效发挥空间大
- 改造后与 Slides 页面形成鲜明对比，便于评估差异化效果

## 六、风险与注意事项

1. **暗色模式对比度** — 确保星光文字在深空背景上满足 WCAG 4.5:1
2. **CelestialCanvas 性能** — 多页面同时使用时注意粒子数量控制
3. **SkyAppShell 兼容性** — 需要考虑是否保留 AppShell 的顶栏/设置功能，或将其整合进深空主题
4. **渐进式迁移** — 每个页面独立改造，不影响其它页面正常运行
5. **响应式适配** — 星空背景在小屏幕上需要适当简化
