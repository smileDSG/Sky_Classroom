# 错题本复习模式设计方案

> **模块**: 天梯工坊 → 复习计划 (review-plan)
> **问题**: 当前复习交互过于简单——点击"开始复习"直接暴露答案，缺少思考-回忆-反馈的完整学习闭环
> **目标**: 构建符合认知科学的三阶段翻转卡片式复习体验

---

## 一、现状分析

### 1.1 当前交互流程

```
[今日待复习列表]
  → 点击"开始复习"
  → 直接显示: 题目 + 我的答案(红) + 正确答案(绿)
  → 点击"答对了 ✓" / "还是错了 ✗"
  → 结束
```

### 1.2 问题诊断

| 问题 | 影响 |
|------|------|
| 答案直接暴露 | 用户没有回忆过程，违背"主动检索"学习原理 |
| 无解题过程 | 只知道对错，不知道为什么对/为什么错 |
| 无分级提示 | 不会做的题只能直接看答案，没有中间地带 |
| 无连续复习 | 每题独立操作，无法批量复习 |
| 无反馈动画 | 缺少正向激励，复习体验枯燥 |

### 1.3 数据现状

`MistakeRecord` 当前字段：

```typescript
interface MistakeRecord {
  id: string;
  problem: string;           // ✅ 题目
  userAnswer: string;        // ✅ 用户原答案
  correctAnswer: string;     // ✅ 正确答案
  cause: MistakeCause;       // ✅ 错因分类
  knowledgePoints: string[]; // ✅ 知识点
  reviewCount: number;       // ✅ 复习次数
  // ❌ 缺失: 解题过程
  // ❌ 缺失: 提示信息
  // ❌ 缺失: 错因详细解释
}
```

## 二、设计方案

### 2.1 核心理念：三阶段翻转卡片

借鉴 **主动检索练习 (Retrieval Practice)** 和 **间隔重复 (Spaced Repetition)** 理论：

```
阶段1: 读题思考 (Recall)     → 激活记忆检索
阶段2: 揭晓对照 (Reveal)     → 反馈校正
阶段3: 自评反馈 (Reflect)    → 元认知评估
```

### 2.2 交互流程图

```
                    ┌──────────────┐
                    │  复习列表页   │
                    │ (review-plan)│
                    └──────┬───────┘
                           │ 点击"开始复习"
                           ▼
              ┌────────────────────────┐
              │  ReviewSession 全屏模式  │
              │  进度: 第 2/5 题         │
              └────────────┬───────────┘
                           │
            ┌──────────────┼──────────────┐
            ▼              ▼              ▼
     ┌──────────┐  ┌──────────┐  ┌──────────┐
     │ 阶段1    │  │ 阶段2    │  │ 阶段3    │
     │ 读题思考  │─→│ 揭晓对照  │─→│ 自评反馈  │
     │          │  │          │  │          │
     │ ·题目展示 │  │ ·答案对比 │  │ ·掌握 ✓  │
     │ ·答案遮挡 │  │ ·解题过程 │  │ ·还错 ✗  │
     │ ·提示按钮 │  │ ·错因分析 │  │ ·再想想 ↺│
     │ ·查看答案 │  │ ·知识点   │  │          │

                                       │
                          ┌────────────┼────────────┐
                          ▼            ▼            ▼
                     还有下一题    最后一题      再想想
                     → 阶段1      → 复习总结   → 回到阶段1
```

### 2.3 各阶段详细设计

#### 阶段1: 读题思考 (Recall)

```
┌─────────────────────────────────────────────────────┐
│  ← 返回    复习模式    第 2/5 题    ████░░░░ 40%     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  📝 题目                                            │
│  ┌─────────────────────────────────────────────┐   │
│  │                                             │   │
│  │  已知函数 f(x) = x² + 2x - 3，求 f(x) 的   │   │
│  │  最小值及对应的 x 值。                       │   │
│  │                                             │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  🔒 答案区域                                        │
│  ┌─────────────────────────────────────────────┐   │
│  │  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │   │
│  │  ░░░  请先自己思考，再点击下方按钮查看  ░░░  │   │
│  │  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  💡 提示        📖 查看解题过程                      │
│                                                     │
│  🔗 关联知识点: 二次函数 · 配方法 · 最值             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 答案区域用 **毛玻璃 + 模糊遮挡**
- "提示"按钮分步揭示（第1次: 思路方向 → 第2次: 关键公式 → 第3次: 首步计算）
- 知识点标签展示，辅助回忆

#### 阶段2: 揭晓对照 (Reveal)

```
┌─────────────────────────────────────────────────────┐
│  ← 返回    复习模式    第 2/5 题    ██████░░ 40%     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  📝 题目                                            │
│  ┌─────────────────────────────────────────────┐   │
│  │  已知函数 f(x) = x² + 2x - 3，求 f(x) 的   │   │
│  │  最小值及对应的 x 值。                       │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  答案对比                                           │
│  ┌─────────────────────────────────────────────┐   │
│  │  ❌ 我的原答案: x = 0, f(x) = -3            │   │
│  │  ✅ 正确答案:   x = -1, f(x) = -4           │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  📖 解题过程                              ▼ 展开    │
│  ┌─────────────────────────────────────────────┐   │
│  │  Step 1: 配方法                              │   │
│  │  f(x) = x² + 2x - 3                        │   │
│  │       = (x + 1)² - 1 - 3                    │   │
│  │       = (x + 1)² - 4                        │   │
│  │                                             │   │
│  │  Step 2: 求最小值                            │   │
│  │  当 (x + 1)² = 0 即 x = -1 时               │   │
│  │  f(x) 取最小值 -4                           │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  ⚠️ 错因分析: 概念不清 — 配方法常数项计算错误        │
│                                                     │
│       [✅ 掌握了]    [❌ 还是错]    [🔄 再想想]       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 解题过程默认折叠，点击展开（避免信息过载）
- 答案对比用红/绿色直观区分
- 错因分析结合 cause 字段生成中文说明

#### 阶段3: 自评反馈 (Reflect)

### 2.4 提示系统分级设计

| 提示级别 | 内容 | 示例 |
|---------|------|------|
| Hint 1 | 思路方向 | "考虑用配方法将二次函数化为顶点式" |
| Hint 2 | 关键公式 | "f(x) = a(x-h)² + k，其中顶点为(h, k)" |
| Hint 3 | 首步计算 | "先提取: f(x) = (x² + 2x + 1) - 1 - 3" |

> **降级方案**: 如果题目没有预设提示，仅提供"查看答案"按钮，不显示提示功能

## 三、数据模型扩展

### 3.1 MistakeRecord 新增字段

```typescript
interface MistakeRecord {
  // ... 现有字段 ...

  /** 解题过程步骤 (可选，AI生成或手动录入) */
```

| 字段 | 来源 | 时机 |
|------|------|------|
| `solutionSteps` | AI 实时生成 | 首次复习时按需生成，缓存到本地 |
| `hints` | AI 实时生成 | 首次复习时按需生成，缓存到本地 |
| `errorExplanation` | AI 实时生成 | 首次复习时按需生成，缓存到本地 |

> **降级方案**: AI 生成失败时，隐藏提示和解题过程区域，仅展示答案对比

## 六、AI 生成集成

### 6.1 调用策略

```
用户进入 ReviewSession
  → 检查 solutionCache 是否有缓存
  → 无缓存: 调用 /api/sky/review/generate-solution (批量)
  → 有缓存: 直接使用
```

### 6.2 API 端点 (新建)

```
POST /api/sky/review/generate-solution
Body: { problems: [{ id, problem, correctAnswer, userAnswer, cause }] }
Response: { solutions: [{ id, solutionSteps, hints, errorExplanation }] }
```

### 6.3 降级策略

| 场景 | 处理 |
|------|------|
| AI 生成成功 | 完整展示解题过程 + 提示 |
| AI 生成失败 | 隐藏解题过程区域，仅展示答案对比 |
| AI 生成慢 (>3s) | 先展示阶段1，后台加载解题过程 |
| 离线模式 | 完全依赖本地缓存，无缓存则仅展示答案 |

## 十、验收标准

- [ ] 点击"开始复习"后答案默认隐藏，需主动点击查看
- [ ] 查看答案后展示解题过程（如有）和错因分析
- [ ] 自评"掌握了"正确调用 `markReviewed(id, true)` 并更新进度
- [ ] 自评"还是错"正确调用 `markReviewed(id, false)` 并重置进度
- [ ] 支持连续复习多题，显示进度
- [ ] 复习结束后展示总结统计
- [ ] 无 AI 数据时降级为仅答案对比模式
- [ ] 键盘快捷键可用
- [ ] 移动端可正常使用
