## 〇、先建立心智模型：这个项目到底在干嘛

**一句话**：这是一个"AI 自动当老师，给学生上一整套课"的平台。输入一个主题（如"初中物理·牛顿第一定律"），系统自动完成：写大纲 → 生成每页内容 → 安排 AI 老师+同学互动 → 导出 PPT/网页课件。

**心智模型（建议背下这张表，看任何代码先对号入座）**：

| 系统模块 | 现实类比 | 一句话作用 |
|---|---|---|
| `lib/ai/` | 后勤/统筹 | 统一"让 AI 干活"，管人管钱防卡死 |
| `lib/generation/` | 编剧组 | 把课程内容一步步写出来(先大纲后细节) |
| `lib/orchestration/` | 现场导演 | 上课时指挥 AI 老师/同学谁先说话 |
| `lib/playback/` | 播放控制台 | 控制课程播放顺序/暂停/继续 |
| `lib/slides/`+`lib/export/` | 美工/后期 | 把内容做成 PPT / 网页课件 |

**完整能力全景（四层）**：
1. 老师上课层（生成→编排→播放→导出）
2. 课堂交互层（白板、聊天/圆桌、语音 TTS/ASR、配图/视频）
3. 学习闭环层（题库、解题、知识图谱、错题本、自适应）
4. 平台能力层（认证、计费、监控、跨端/离线、状态/存储）

## 四层八块详解

### 第 1 块 老师上课·AI 网关层 `lib/ai/`

**它解决什么**：直接调 AI 满地是坑——慢(要超时)、失败(要重试)、被限流(换key)、贵(要记账)、输出不可靠(要校验)。

**零件① `KeyPool`（钥匙池）**
- `inflight` = 每个 key 手上正在处理的请求数
- 选出最空闲的一批(least-inflight 最小在途)，再轮询(round-robin)公平挑选
- 连续失败 3 次(`MAX_FAIL_COUNT`)→ 判不健康(熔断)→ 冷却 60s(`HEALTHY_RESET_MS`)自动恢复

**零件② `callLLM()`（统一大门）**
- 超时：`AbortController + setTimeout`
- 指数退避重试：间隔 `2000ms × 次数`，越失败等越久
- 429 限流 → 告诉钥匙池换一个 key，不是傻重试同一个

**零件③ `cost-tracker`**：按 provider/model 精确匹配单价，找不到退回 `provider/*` 通配，按 provider、session 聚合记账。

**面试一句话**：不是"我调用了 AI"，而是"把 AI 调用做出了生产级可靠性"（超时/重试/换钥匙/熔断/自愈/记账）。

### 第 2 块 老师上课·生成管线 `lib/generation/`

**核心思想**：大任务拆小步，每步只干一件事，每步可校验，错了只重做一步。

**两阶段管线**（画骨架再填血肉）：
- 阶段1 `outline-generator`：先写大纲(短、好控)
- 阶段2 `scene-generator`：每页单独生成(出错了只重做这一页)

**`json-repair.ts`（兜 AI 输出坏数据）**：`parseJsonResponse` / `parseWithSchema` / `registerRepairStrategy`——探测常见坏法(前后缀包裹/转义错误/截断)→ 修复策略修 → 修不了再重试。

**`quality-scorer.ts`**：`scoreContent` 打分 + `isAcceptable` 判断，不合格重生成 → 形成"生成→打分→重来"闭环。

**`incremental.ts`**：`reorderScenes` / `regenerateScene`——支持局部重做，不用整课重来。

**面试一句话**：把不可靠的 AI 生成，用"拆阶段+校验+修复+打分+局部重做"包装成可靠、可控、可维护的内容生产线。

### 第 3 块 老师上课·多智能体编排 `lib/orchestration/`（技术最亮）

**LangGraph 三概念**：节点 = 工作间；边 = 通道；条件边 = 岔路口的判断路牌。

**图拓扑(最能答"多轮对话怎么循环")**：
```
START → director →(条件边)→ agent_generate →(回环)→ director →(END时)结束
```
关键：`agent_generate → director` 的回环 = 对话可持续的根本原因。

**导演节点省钱的巧妙权衡(重点)**：
- 简单情况 → **纯代码 fast-path，零 LLM 调用**（单agent首轮、用户手动点名、QA 首轮）
- 复杂情况 → 才让 LLM 拍板（`buildDirectorPrompt` + `summarizeConversation` + `parseDirectorDecision`）

**agent-node 节点**：产出分 文本/动作/流式片段 三部分；动作部分写成 `WhiteboardActionRecord` 发前端执行。

**记忆与长对话**：`agent-memory`(记住自己说过啥) + `conversation-compression`(历史太长就压缩/概括，防上下文爆掉)。

**面试金句**：用 LangGraph 把多 AI 互动画成可控流程图，按"能省则省"混合 代码路由+LLM 路由，靠回环实现多轮，靠记忆和历史压缩保证长对话不断。

### 第 4 块 老师上课·播放状态机 `lib/playback/`

**为什么必须用状态机**：真实课会中断(提问停顿/用户插话/暂停记笔记)，散落的 if 容易"状态漂移"。

**状态图**：`idle →(start) playing →(pause) paused →(resume) playing`，讨论时进 `live`，结束回 `idle`。`PlaybackEngine` 方法：`start/pause/resume/stop/confirmDiscussion/handleEndDiscussion/handleUserInterrupt`。

**贴心细节**：
- 暂停会保存 TTS 读到哪、播到第几句；恢复时**续播**，不从头来
- 不同语言语速不同(英词~240ms、中字~150ms，用 CJK 阈值判断)
- `consumedDiscussions` 防止同一讨论被反复触发

**面试价值**：复杂前端多状态交织，用集中状态机代替散落 if；暂停续播要保存"中间现场"。

### 第 5 块 老师上课·幻灯片智能体 + 导出 `lib/slides/` `lib/export/`

**四道工序(每道一个 AI 智能体)**：Planning → Section → Page-Design → QA。每道用 **Zod schema 强约束**输出格式，装不进模子判不合格。

**QA 分三层(按成本从小到大)**：
1. 结构 QA（0 次 LLM）→ 框架完整
2. 内容 QA（1 次 LLM）
3. 视觉 QA
→ 结构层就发现问题就拦下，省掉后面 token。

**两个自研 workspace 包(简历亮点)**：
- `mathml2omml`：LaTeX → 预处理 → MathML → OMML；预处理修 `Zn2+→Zn^{2+}`、`10^37→10^{37}`；转不出就降级成 SVG 图兜底
- `pptxgenjs`：定制 PPTX 生成，支持阴影/描边/渐变/透明/SVG path

**还有 HTML 导出 + 课堂 ZIP 备份**(.maic.zip 源文件可再导入)。

### 第 7 块 学习闭环层(灵魂/我是差异化重点)

一句话闭环：**做题→错题→归因→知识图谱算掌握度→艾宾浩斯排复习→自适应推荐→再做新的**。

**① 题库+判分 `question-bank/` `quiz/`**
- 多格式导入：CSV/JSON/PDF/XLSX
- 题目字段：subject/grade/difficulty/type/content/answer/explanation/knowledgePoints/steps/similarQuestions/problemHash
- 判分：客观题本地判分(对答案不花钱)；简答题标 short_answer 或 AI 点评；problemHash 去重

**② 解题 `lib/solve/`**：拿到题 → 多步骤生成为主、(讲题) → 流式输出 + 判分批改

**③ 知识图谱 `lib/knowledge-graph/`(技巧核心)**
- 节点=知识点(用 `inferCategory` 按正则自动归：代数/函数/几何/概率/统计/数列/微积分…)
- 边关系三种：prerequisite(前置)/related(相关)/extension(扩展)
- **mastery 掌握度公式(背下来)**：
  ```
  100 − 错题数×10 + 复习加分(最多60) − 超7天未复习的遗忘衰减   [夹在0~100]
  ```

**④ 错题本+复习 `lib/mistakes/` `lib/schedule/`**
- 错误自动归类：计算/概念/推理/阅读/粗心(calculation/concept/reasoning/reading/careless)
- **艾宾浩斯曲线复习间隔 `[1,2,4,7,15,30]` 天**
- 复习视图三档：today(该复习)/overdue(逾期24h)/upcoming(未来7天)

**⑤ 自适应 `adaptive-learning/` `cloud-mind/`**：把错题/掌握度/复习汇总成推荐引擎 + spaced-repetition，动态推荐下一步学什么。

## 面试完整自述话术(建议背)

> 这个平台是让 AI 自动当老师的一体化产品：底层是统一的多供应商 AI 网关(管超时/重试/换 key/记账)；中间两阶段生成管线自动产出课程；上课时用 LangGraph 编排多个 AI 角色互动，配合白板、语音、聊天让课"活"起来；课后接学习闭环——题库判分、知识图谱算掌握度、错题本按艾宾浩斯曲线排复习、自适应引擎推荐下一步；再配上账号、计费、监控、跨端离线和多存储后端，成为一个能落地商业化的完整系统。
