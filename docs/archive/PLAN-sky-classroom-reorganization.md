# 天空课堂完整重编排计划

## 任务目标

围绕“学生输入知识点，生成一堂可学习、可练习、可反馈的互动课堂”重新组织产品信息架构，解决入口分散、主页职责不清、用户看不到个性化计划的问题。

## 选定方案 A

1. `/` 作为天空课堂主入口：用户输入知识点后生成讲解课堂；同时提供轻量的“为你安排”预览，让用户知道今天推荐学什么以及为什么。
2. `/sky` 作为学习工作台：集中展示学习画像、当前目标、今日具体任务、7/14 天学习路径、学习反馈和需要复习的薄弱点。
3. `/sky/teaching` 作为独立授课/备课工作区：承接教师视角的课程生成、授课控制、课堂资料和教学工具，不与学生首页争夺主入口。
4. `/sky/cloud-mind` 作为资源中心：承接题库、拍照搜题、PPT、讲义、课程资源、联网搜索、模板、大纲审阅等工具，保留已有能力。

## 学习闭环

```text
学习画像 → 学习计划 → 知识点讲解 → 练习反馈 → 更新知识状态 → 调整下一步计划
```

每项计划任务都需要有明确的推荐原因、预计用时和行动入口；任务完成后更新状态并为下一步提供承接，避免只展示静态统计。

## 页面设计

### 天空课堂首页

- 首屏主行动是输入知识点并开始讲解。
- 在输入区下方增加轻量“为你安排”预览：当前学习目标、推荐下一讲、预计时间、推荐原因、进入完整学习工作台。
- 保留最近生成课堂、生成进度、模板、PDF/联网搜索和互动模式等已有能力，但将工具入口收敛到资源中心或次级操作。

### 学习工作台

- 顶部明确显示画像摘要、当前目标、掌握度和连续学习状态。
- 首屏显示今日任务列表，每项包含任务类型、知识点、预计时长、推荐原因和开始操作。
- 展示接下来 7/14 天的路径，区分待学习、进行中、待复习和已完成。
- 提供学习洞察、错题复盘、知识图谱、学习记录和画像编辑入口。
- 任务完成后回到工作台，刷新知识状态和后续计划。

### 授课/备课工作区

- 保持独立的教师工作流入口和课程生成能力。
- 课程生成、课堂编排、幻灯片、讲义、题目和授课控制都在此或资源中心内承接。

### 资源中心

- 以工具分组呈现学习资源、练习工具、课程制作和资料管理。
- 保留已有功能，不因为信息架构调整删除能力。

## 分阶段执行

1. 建立本计划文件，确认页面职责和导航分工。
2. 阅读并复用现有学习画像、学习计划、今日任务和路径组件。
3. 补强学习工作台的任务信息密度、推荐原因和行动承接。
4. 在天空课堂首页增加个性化计划预览，并保持知识点讲解为唯一主行动。
5. 检查 `/sky/teaching` 和 `/sky/cloud-mind` 的入口关系，确保教师功能与学生学习流分离但可达。
6. 运行格式检查、ESLint、TypeScript 检查和 diff 检查，记录既有问题与本次问题。

## 风险与控制

- 既有工作区包含大量未提交改动：仅修改本次涉及文件，不覆盖已有计划和数据。
- 个性化 API 可能未登录或返回空数据：保留空状态和默认学习任务，保证主页可用。
- 学习计划功能已有多条路线：优先通过现有组件和 API 统一展示，避免新增平行数据模型。
- 全量 TypeScript 当前存在已知错误：验证时区分本次改动错误和基线错误。

## 预期产出

- 用户进入首页即可生成知识点讲解，并能看到与画像相关的下一步建议。
- 用户进入学习工作台即可理解当前目标、今日任务和未来路径，并能直接开始行动。
- 教师授课/备课能力保留在独立工作区，资源工具仍然可访问。
- 学习行为、反馈和后续计划形成可理解的闭环。
