# 智眸无界 · 3 分钟黄金演示脚本

> 原则：全程只走一条路，其他页面一概不碰。功能多不是问题，**不主动展示的功能就是深度储备**，答辩时用一句话带过即可。

---

## 一、开场定位（先背下来这三句）

评委问"这是什么"时，永远用同一套话：

1. **一句话**：「智眸无界是一个 AI 多智能体互动课堂——你给一个主题，一组 AI 智能体帮你备好课、当好老师、扮好学生，直接上课。」
2. **一句技术**：「底层用 LangGraph 状态机编排多智能体协作，四段式管线生成课件，28+ 种课堂动作引擎驱动教学过程。」
3. **一句价值**：「老师从备课中解放出来，学生得到的不是录播，是会互动的课堂。」

---

## 二、3 分钟主线脚本（有 Key 环境，正式演示用）

### 0:00–0:20 · 开场（别登录、别翻页，直接说）

> "大家好，这是智眸无界。传统网课是录播，学生看完了就完了；我们做的是**会互动的多智能体课堂**。我用 3 分钟，从一个主题开始，到一节能上的课结束。"

**操作**：停在首页输入框前，光标闪着，什么都别点。

### 0:20–1:00 · 输入主题 → 多智能体生成（展示"大脑"）

**操作**：输入框打 `勾股定理`（提前练熟，别现场想），开启互动模式，点生成，立刻切到生成进度页。

> "现在后台是一组智能体在协作，不是一次模型调用：**规划智能体**定课程结构，**章节智能体**逐节写内容，**页面设计智能体**排版，最后**质检智能体**打分把关——每一段都有结构化约束，不合格会自动重试。注意看进度，每一步是谁在干活都看得见。"

**要点**：这一段的价值是"多智能体"三个字落地成看得见的流程，别急着划过去。

### 1:00–2:20 · 课堂播放（展示"灵魂"，时间给最足）

**操作**：生成完成，进入课堂页。让 AI 教师开始讲课。

按顺序触发 4 个动作，每个 15–20 秒：

1. **AI 教师讲课 + 板书**：教师边讲边在白板写/画（`a²+b²=c²` 画直角三角形）。
   > "教师智能体不是念稿，它调用动作引擎实时板书。"
2. **学生智能体提问**：切一个"学生"发言提问，教师回应。
   > "课堂里还有多个学生智能体，各有画像，会真的提问、真的会答错——这是 LangGraph 导演图在调度整个课堂节奏。"
3. **激光笔/聚光灯**：圈出图形重点。
   > "28 种课堂动作，这只是三种。"
4. **学生答题/互动**（如时间够）：
   > "学生听没听懂，课堂里立刻有反馈，这是和录播的本质区别。"

### 2:20–2:50 · 导出 + 收尾

**操作**：进入幻灯片页，点导出 PPTX，展示下载的文件。

> "整节课可以一键导出成标准 PPT，老师拿回去还能改。到这里——**一个主题进去，一节完整的、可互动、可导出的课出来**，全程没有人工参与。"

### 2:50–3:00 · 结束语

> "刚才看到的是单节课堂，系统里还有学习路径、错题回顾、自适应学习等模块。我们的判断是：AI 教育的下一步不是更聪明的录播，而是**多智能体把课堂本身重建一遍**。谢谢。"

## 三、零密钥 90 秒版（评委机器没 Key / 网络差时的预案）

路径：打开 `http://localhost:3000/sky/software-cup`

> "这个页面内置了完整的预置演示：多智能体轨迹、生成资源、质检报告全部可见，**不调用大模型、零密钥、零联网**——因为我们把一次真实生成的完整结果预置在了系统里，接口在没有模型时会自动优雅回退，这也是系统容错设计的一部分。"

用 90 秒讲：定位（20s）→ 轨迹/资源/质检三块各指一遍（50s）→ 结束语（20s）。

## 四、演示前检查清单（照着打勾）

**提前一晚**
- [ ] 完整跑一遍主线脚本，计时 ≤ 3 分 30 秒
- [ ] 用 `勾股定理`（或固定主题）**预先生成好一节课**留在课堂列表里——现场生成失败时直接打开这节兜底
- [ ] 录一遍完整操作屏视频（生成→课堂→导出），存本地 + 传手机
- [ ] 导出好的 PPTX 文件放在桌面，防止现场导出慢

**现场开场前 10 分钟**
- [ ] 演示账号能登录（demo / SkyClassroom123!）
- [ ] 关闭系统通知、清空浏览器其他标签页、字体缩放 110%
- [ ] 网络不通 / Key 失效 → 立刻切零密钥版（第三节）
- [ ] 生成卡住超过 40 秒 → 直接说"预生成了一节，我们直接看课堂效果"切兜底课

**三条铁律**
1. 现场不即兴点任何主线之外的页面
2. 生成过程慢就讲进度面板，绝不干等冷场
3. 翻车不道歉不解释技术细节，直接切预案继续讲

## 五、评委高频问题 · 15 秒标准答案

| 问题 | 答案 |
| --- | --- |
| 和普通 AI 生成 PPT 有什么区别？ | PPT 工具给的是文件，我们给的是**课堂**——有师生互动、有节奏调度、有实时反馈，导出 PPT 只是副产品。 |
| 多个智能体怎么协作的？ | LangGraph 状态机当"导演"，管理教师/学生的发言回合、讨论和辩论；课件走四段式管线，每段 Zod Schema 约束 + 3 次指数退避重试。 |
| 模型挂了/没 Key 能用吗？ | 能。接口缺模型时优雅回退到预置结果，刚才的零密钥演示就是这么工作的——这是容错设计，不是补丁。 |
| 老师在里面的角色是什么？ | 老师从"备课+上课"变成"审课+控场"，生成的课件和课堂都可编辑、可导出，AI 是助教不是替代。 |
