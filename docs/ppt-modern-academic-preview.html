折射定律

03 / 08
光从真空射入介质时，入射角的正弦与折射角的正弦之比保持不变，这一比值称为该介质的折射率 n。

斯涅尔定律

n₁·sinθ₁ = n₂·sinθ₂
折射率仅取决于介质本身，与入射角无关。

全反射与临界角

05 / 08
当光从光密介质向光疏介质传播且入射角超过临界角 C 时，折射光线消失，光被完全反射回原介质。

临界角公式

sin C = 1 / n

发生条件

① 光密 → 光疏
② 入射角 > 临界角
