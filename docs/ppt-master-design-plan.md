# PPT 母版改造方案 —— "现代学术"默认主题试点

> 目标：把云端智囊·PPT 生成从"二十几年前的默认模板感"改造成"有现代设计感的学生/教师可用成品"。
> 原则：**开放授权设计规范 + 自产母版**，不爬版权商用模板；预览与 PPTX 导出共用同一渲染源。
> 本方案先做 **一套** 默认主题（"现代学术"）作为试点，效果确认后再铺开。

---

## 0. 问题诊断（不搞大改，先对症）

当前观感"老土"的工艺根源（非审美问题）：

1. **字体落地失败**：默认中文字体几乎全是微软雅黑 / 黑体 / 仿宋，正文字号 13~14。这就是 Office 默认排版的祖师爷，一上雅黑，观感直接回到 2000 年。
2. **配色被规则暴力守恒**：`sanitizeColors()`/`sanitizeFonts()` 会把"盘里没有的颜色/字体"一律拍回默认。12 套配色看着多，实际全被拉回"天空蓝 + 雅黑"这一种 → 千篇一律。
3. **版式是"满屏卡片盒"**：默认 `cardStyle: accent-left-bar` + 小字 + 到处是框，和现代演示（大字号、留白、非对称、弱边框）正好相反。
4. **双渲染源**：预览与导出的 PPTX 不是同一套渲染 → 两边都需要改，否则"两个都丑"。

---

## 1. 设计规范（"现代学术"默认母版）

### 1.1 字体系统

中文字体是"离开二十年前感"的最大变量。**统一用思源黑体（Noto Sans CJK SC，SIL OFL 授权，可免费商用）**，彻底告别微软雅黑。学术场景禁用宋体、楷体（衬线/手写感不专业）。

| 层级 | 字体 | 字重 | 说明 |
|---|---|---|---|
| 大标题（封面/章节页） | 思源黑体 | Bold/Heavy | 36–64pt，加粗拉开层级 |
| 内页标题 | 思源黑体 | Medium/Semibold | 28–32pt，加粗 |
| 正文/要点 | 思源黑体 | Light/Regular | ≥24pt，宁大勿小 |
| 强调文本 | 思源黑体 | Bold | 用于高亮关键词，不用衬线/字体切换去做强调 |

英文/数字统一用 **Arial 或与思源黑体搭配的无衬线体（如 Inter）**，最多 2 款字体（标题一款 + 正文一款），遵守"≤2 fonts"原则。

字号底线：正文 ≥24pt，标题 ≥36pt，任何可见文本不低于 18pt。
（依据：」pageplate"24pt body / 36pt+ heading / 18pt floor"，study.com 同推荐）[$TRAE_REF](https://placeplate.com/blog/how-to-design-academic-presentation/)

### 1.2 配色系统

现代学术配色走"深色主色 + 单一强调色"路线，克制、高对比、权威感。**每套主题只保留 4 个角色色，其余一律由 AI 在这套盘内取值，不许发明。**

**"现代学术"盘（试点主推）：**

| 角色 | HEX | 用途 | 用量上限 |
|---|---|---|---|
| 主色（深藏青） | `#1B2A4A` | 标题、Hero 区、强调条 | ≤40% |
| 背景（近白） | `#FAFAFA` | 页面底色 | — |
| 正文（近黑） | `#2D3436` | 正文文字 | — |
| 强调色（单一） | `#C9A227`(金) / `#0984E3`(信号蓝) 二选一 | 高亮、图表主线、重点框 | ≤10% |

配色铁律：
- **每页最多 3 个颜色角色**（主色 + 背景 + 强调），正文近黑。
- 深色文字配浅背景（高对比、最安全），**禁止红字蓝底**等低对比组合。
- 有区分度但可被红绿色盲识别，避免红/绿并置作唯一区分手段（仅用于必要时，色盲友好）。

依据：presentationgo 建议"navy 主色 + 白底 + 单一 accent"，presentersarena 学术配色用"近黑文字 + 近白底 + 信号蓝点缀"。[$TRAE_REF](https://www.presentationgo.com/article/best-colors-for-presentations/) [$TRAE_REF](https://presentersarena.com/design/aesthetics/the-best-presentation-color-schemes-for-every-occasion-with-hex-codes)

> 备注：2026 趋势偏"暖中性色"（米灰、陶土），可留作**第二套"暖现代"主题**后续试点，不进本默认盘。[$TRAE_REF](https://www.slide24h.com/blog/mau-sac-thiet-ke-slide-2026-bang-mau-trending-phoi-chuan)

### 1.3 版式系统

从"卡片盒"转向"留白 + 大块面 + 非对称"。母版设计成**固定骨架，AI 只填内容槽**，堵死"乱排"。

**内页母版（约 6 套骨架）：**
1. 封面（大标题 + 单强调条 + 大幅留白）
2. 章节过渡页（大字 + 极简）
3. 要点页（一句式页面标题 + 2–4 条正文，左侧对齐）
4. 双栏对比页（左右两栏，栏内不超过 4 条）
5. 图解/流程页（时间轴或 3–4 步横向流程）
6. 数据/表格页（图或表 + 一句结论句）

**版式铁律：**
- 每页**一个观点**，正文不超过 2–4 条列表项，列表项≤10 词。
- **留白 ≥ 1/3 版面**（负空间让重点透气）。
- 页标题一律左上角左对齐（封面除外）。
- 标题最多 2 行、列表块最多 2–4 项。
- 弱化圆角卡片边框 → 用留白与字号层级代替框线。

依据：UBC 幻灯片设计 10 条中强调"约 1/3 版面留白 + 6×6 规则"[$TRAE_REF](https://lfs-cornelis-2021.sites.olt.ubc.ca/files/2021/02/am_i_pretty_10_tips_to_designing_visually_appealing_slideware_presentations.pdf)；scispace 版式清单"句标题左上角左对齐、标题≤2 行、列表 2–4 项、大量留白"。[$TRAE_REF](https://scispace.com:443/pdf/rethinking-the-design-of-presentation-slides-creating-slides-344v11ftwq.pdf)

## 2. 工程落地要点

1. **母版 = 合规自产**：上述字体（思源黑体 OFL）+ 配色/版式骨架均为自造规范，无第三方商用模板版权雷区。
2. **放宽"回收到默认"的强度**：`sanitizeFonts/sanitizeColors` 改成"在主题盘内自由选中"而不是全拍回天空蓝+雅黑。AI 仍不能超盘，但盘内可以有变化。
3. **内容槽字数/条数上限**：母版约束 AI，防内容溢出破版；内容过多时按"合并条目/缩字号"自适应，而非撑破骨架。
4. **双渲染源统一**：预览与 PPTX 共用同一母版渲染，避免"预览好看、导出破版"。
5. **文本直排 / 缩放**：标题大字号、正文 24+ 在两种渲染里都要验证不换行溢出。

## 3. 测试方案

### 3.1 样式不变量（自动化，快）
- **字体断言**：所有页面标题字体 ∈ {思源黑体 Bold/Heavy}，正文 ∈ {思源黑体 Regular/Light}；无任何元素使用微软雅黑/宋体/楷体/仿宋。
- **字号断言**：标题 ≥36pt、正文 ≥24pt、任何可见文本 ≥18pt。
- **配色断言**：每页用色角色集合 ∈ {主/背/正/强调}，且强调色为盘内指定值，无越盘色；非页面级装饰无红色背景+蓝色字等低对比组合。
- **版式断言**：列表项 ≤4 条、标题 ≤2 行、页面级留白比例 ≥1/3（以背景色像素占比估算）。

### 3.2 视觉审美（人工/截图，快）
- **双端一致性**：同一份大纲分别出预览图与导出 PPTX 截图，逐页比对版式是否一致。
- **对照测试**：同一主题下"改造前 vs 改造后"生成同一课程，人工 A/B 打分（≥7/10 视为通过，重点看字体、留白、色彩三个维度）。

### 3.3 内容健壮性（自动，中）
- **多科目冒烟**：文（历史）、理（数学，含公式）、应用（物理/信息）各生成 1 份 8–10 页 PPT，断言 4.1 与公式嵌入（MathML/OMML，走 `packages/mathml2omml`）均不破版。
- **长内容自适应**：输入超长知识点列表，断言母版自动合并条目/缩字号后仍不溢出、不重叠、不留白突兀。

### 3.4 回归（自动，慢）
- 现有 QA 三轮重试、缓存、个性化上下文注入不因本次改造回归（跑既有 `pnpm test` + 相关单测）。
- PPTX 导出可打开、无字体缺失告警（演示环境含清晰度检查）。

## 4. 验收清单（试点 = 一套"现代学术"）
- [ ] 字体系统落地（思源黑体全替换，字号拉开层级）
- [ ] "现代学术"配色盘落地，放宽回收强度
- [ ] 6 套内页母版骨架，AI 只填内容槽
- [ ] 预览与 PPTX 双端渲染统一
- [ ] 3.1 自动化断言 + 3.2 人工 A/B ≥7 分通过
- [ ] 3.3 文理应用三科冒烟通过

试点通过后再评估铺开第二套"暖现代"主题与更多学科默认盘。
