# 星际试炼场产品体验优化设计

日期：2026-09-25

## 目标

在保留现有出题、题库练习、答题、解析、学习画像更新和错题复盘能力的前提下，降低生成前的配置成本，增强任务期待感，并让用户在正式生成前确认题目风格。

本次仅改造星际试炼场的配置态和出题输入数据。生成后的答题流程继续使用现有全宽工作区。

## 页面结构

配置态继续使用现有双栏结构：

- 左侧为快捷试炼包、出题模式、知识点、练习目标、难度、题量、题型和主操作按钮。
- 右侧为动态试炼摘要、快捷键提示和一题真实样题预览。
- 页面标题继续使用统一的 `FeaturePageHeader`。

页面描述使用：

> 选择试炼主题，开启专属 AI 出题，右侧实时预览你的试炼任务。

AI 出题主按钮使用“开启试炼”。题库模式继续使用“从题库抽题”，避免混淆生成和抽取行为。

## 快捷试炼包

页面配置区顶部增加四个快捷试炼包。点击后一次性更新练习目标、难度、题量和题型。知识点处理遵循以下规则：

- 当前已有知识点时保留当前知识点。
- 当前没有知识点时，优先使用学习画像推荐知识点。
- 没有学习画像推荐时保持为空，让后端选择核心考点。

预设配置：

| 试炼包 | 难度 | 题量 | 题型 | 练习目标 |
| --- | --- | ---: | --- | --- |
| 基础巩固 | easy | 5 | choice | practice |
| 考前速练 | medium | 10 | choice | mock |
| 错题复盘 | easy | 5 | fill | diagnose |
| 压轴挑战 | hard | 5 | choice | diagnose |

选中快捷包后使用淡紫背景、紫色边框和短暂淡入反馈。用户随后手动修改任意配置时，快捷包仍可显示为“自定义”，不强制保持某个预设的激活状态。

## 知识点推荐

知识点输入保留自由文本能力，并增加下拉建议。建议由以下来源合并、去重并限制数量：

1. 当前学习画像中的薄弱点。
2. 当前学习路径的下一知识点。
3. 内置的常见学科知识点。

输入文本时按包含关系过滤建议。输入框为空并获得焦点时，优先展示个性化建议。点击建议后写入知识点并关闭下拉。键盘交互至少支持 Escape 关闭；不改变现有 Ctrl/Cmd + Enter 生成快捷键。

## 练习目标

新增 `QuizGoal`：

- `practice`：单纯刷题，覆盖核心概念和常见题型。
- `diagnose`：查漏补缺，优先考查易错点、边界条件和常见误区。
- `mock`：限时模考，题干与选项更接近考试表达，减少教学提示。

练习目标需要从页面传入 `/api/sky/cloud-mind/quiz`，写入后台任务输入，并传给 quiz agent。Agent 在用户提示词中加入对应要求。

`mock` 在本阶段只控制出题风格和解析呈现策略，不新增倒计时器、自动交卷或考试监考功能。

## 配置记忆

使用浏览器 `localStorage` 保存最近一次有效配置：

- 出题模式
- 学科
- 知识点
- 难度
- 题量
- 题型
- 练习目标

恢复优先级从高到低为：

1. URL 查询参数。
2. 最近一次本地配置。
3. 学习画像推荐。
4. 页面默认值。

本地数据必须经过字段白名单和枚举校验。解析失败时静默忽略，不阻断页面使用。生成状态、样题内容、用户答案和评分不写入本地配置。

## 动态试炼摘要

右侧标题改为“试炼摘要”，实时显示：

- 出题来源：AI 出题或题库练习。
- 主题。
- 难度。
- 数量。
- 题型。
- 练习目标。

摘要底部显示 Ctrl/Cmd + Enter 快捷生成提示，并将提示放在主按钮附近，使其在左侧也可见。

## 真实样题预览

右侧摘要提供“预览 1 道样题”按钮。预览采用按需生成，不随每次配置变化自动调用模型。

### 状态

- `idle`：尚未生成预览。
- `loading`：正在生成。
- `ready`：展示题干及选择项或题型提示，不展示答案和解析。
- `stale`：生成预览后配置发生变化，保留旧内容但明确标记已过期，并提供重新预览。
- `error`：展示简短错误和重试入口。

### 接口

新增独立的同步或短轮询预览接口，输入字段为：

- subject
- topic
- difficulty
- questionType
- goal

接口固定生成 1 道题，使用现有配额校验、鉴权、错误清洗和 quiz agent。预览结果只返回展示所需字段，不返回正确答案和解析。

相同用户和相同规范化配置使用服务端缓存。页面同时保存当前会话缓存，避免用户在同一配置上重复请求。每次真实预览按现有 LLM 调用规则计入额度。

为防止旧请求覆盖新配置，前端为每次请求保存配置签名；响应返回后只有签名仍匹配时才进入 `ready`，否则进入 `stale`。

## 后端数据流

正式生成数据流：

1. 页面提交 `subject`、`topic`、`difficulty`、`count`、`questionType` 和 `goal`。
2. API 校验并规范化 `goal`。
3. 后台任务存储 `goal`。
4. Job runner 将 `goal` 传给 `generateQuiz`。
5. `buildQuizUserPrompt` 根据目标追加出题约束。
6. 缓存键包含 `goal`，避免不同练习目标共享错误结果。

预览接口复用同一 prompt 构造逻辑，固定 `count = 1`。

## 错误处理

- 本地配置损坏：忽略并使用其他配置来源。
- 知识点建议为空：保持自由输入，不显示空下拉框。
- 样题预览失败：保留当前配置，允许重试，不影响正式生成。
- 样题预览超时：显示请求失败，不自动无限重试。
- 配额不足：沿用现有配额错误表达，不退化成假样题。
- 正式生成失败：沿用现有后台任务错误和重试行为。

## 视觉与动效

- 品牌操作色使用当前统一紫色。
- 正确、错误和警告继续使用绿色、红色和橙色语义色。
- 快捷包、练习目标和配置选项复用同一种弱底色选中态。
- hover 使用浅紫背景和紫色边框。
- 选中反馈采用 150 至 200 毫秒的颜色与轻微位移动画。
- 遵循 `prefers-reduced-motion`，不增加持续循环装饰动画。
- 使用现有 Lucide 图标，不在文案中加入 emoji。

## 测试与验收

### 单元与组件测试

- 快捷试炼包能正确填充全部相关配置。
- 手动修改后配置摘要同步更新。
- 本地配置按优先级恢复，非法数据被忽略。
- 知识点推荐能合并个性化与内置建议并过滤。
- 练习目标随正式生成请求发送。
- 样题预览展示加载、成功、失败和过期状态。
- 配置改变后旧预览响应不会覆盖新配置。

### Agent 与 API 测试

- 三种练习目标分别进入 prompt。
- 正式任务和预览缓存键包含练习目标。
- 预览接口固定生成一题，且响应不包含答案和解析。
- 非法 goal 回退到 `practice`。

### 回归验收

- AI 正式出题仍通过后台任务完成。
- 题库练习不触发样题生成逻辑。
- Ctrl/Cmd + Enter 仍能生成。
- 正确、错误、解析、评分、学习画像和错题复盘流程不受影响。
- TypeScript、ESLint、相关 Vitest 和格式检查通过。

## 非目标

- 本轮不新增倒计时器、自动交卷和监考模式。
- 本轮不重做生成后的答题页面。
- 本轮不新增多知识点组合编辑器。
- 本轮不生成假样题或静态模板题代替真实模型预览。
