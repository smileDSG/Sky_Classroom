# Sky 学习入口重编排设计

## 背景

当前 Sky 学习线同时暴露了三个近似总控入口：

- `/sky`：摘星锦囊。
- `/sky/learning`：天梯工坊。
- `/sky/study-lab`：个性化学习工作台。

三者都在表达“今日任务、学习画像、学习路径、下一步建议”。用户进入后容易把它们理解成三个并列工作台，不知道应该先看哪个、从哪里开始，也难以分辨“天梯工坊”和“学习实验室”的差异。

本次设计目标不是删除学习能力，而是删除显眼重复入口，重新编排用户路径。

## 核心决策

采用“删入口、保功能、按场景触发”的重编排方案。

- 摘星锦囊保留为今日学习首页。
- 天梯工坊保留为学习路线和计划中心。
- 个性化学习工作台从主流程隐藏，相关信息合并回天梯工坊。
- 具体工具不再平铺成入口矩阵，而是在今日任务、路线节点和更多工具中按需出现。

## 非目标

- 不删除 `/sky/study-lab` 路由，避免断链。
- 不移除错题复习、智能练习、生成课程资源、知识图谱、画像等业务能力。
- 不重写后端数据接口。
- 不改变云端智囊本身的工具能力。
- 不做大规模视觉风格重建。

## 新信息架构

### 摘星锦囊：今日学习首页

摘星锦囊回答一个问题：用户今天该做什么。

导航可显示为“今日学习”，页面标题或品牌语境保留“摘星锦囊”。第一屏只保留：

- 今日推荐任务。
- 推荐原因。
- 一个主行动：开始今日任务。
- 简短状态指标：到期复习、今日学习、连续学习、掌握度。

画像不足时，在首页出现轻量提示：

- 标题：完善学习画像。
- 说明：补充目标、薄弱点和偏好后，今日任务会更准。
- 行动：去完善画像。

首页不展示复杂学习路线、推荐依据列表、工具矩阵或多个并列主按钮。

### 天梯工坊：学习路线页

天梯工坊回答两个问题：为什么这样学，以及接下来怎么走。

页面结构改为：

1. 今日计划摘要。
2. 学习路线。
3. 推荐依据。
4. 更多工具。

今日计划区保留一个主按钮：开始今日任务。次级操作可以是调整计划或刷新数据。

学习路线区展示当前阶段、后续阶段和薄弱点优先级。完整路线入口保留在该模块底部。

推荐依据默认精简展示，复杂证据折叠，避免第一屏信息过载。

更多工具默认折叠，用户有明确目的时再展开，包含：

- 智能练习。
- 错题复习。
- 生成课程资源。
- 知识图谱。
- 学情画像。

### 个性化学习工作台：隐藏详情页

`/sky/study-lab` 暂时保留，但不作为主导航或天梯工坊显眼入口出现。

该页面后续可以有两种用途：

- 作为内部演示或数据详情页。
- 逐步清空重复内容后，重定向到 `/sky/learning`。

首版只移除主流程中的显眼入口，避免引入重定向风险。

## 入口处理表

| 原入口 | 处理方式 | 新进入方式 |
| --- | --- | --- |
| 个性化学习工作台 `/sky/study-lab` | 从主路径隐藏，路由保留 | 信息合并到天梯工坊，必要时通过调试或详情链接进入 |
| 学习工具入口五卡片 | 改为折叠的“更多工具” | 天梯工坊底部展开 |
| 画像按钮 | 保留但换位置 | 首页画像不足提示，或天梯工坊画像摘要旁 |
| 生成课程资源 | 不作为天梯工坊主 CTA | 放在云端智囊；当今日任务需要资料时场景触发 |
| 查看完整路线 | 保留 | 学习路线模块底部 |
| 到期复习、智能练习、错题复盘 | 保留 | 通过“开始今日任务”自动进入 |

## 页面行为

### 今日任务选择

今日任务优先级：

1. 有到期复习时，优先复习。
2. 有画像推荐时，进入推荐的学习工具。
3. 没有学习信号时，引导完成诊断。
4. 画像不足但已有少量学习数据时，提示完善画像作为辅助入口。

### 场景触发入口

用户不先看到工具列表，而是看到系统选择后的任务。

示例：

- 到期复习大于 0：主按钮进入复习。
- 当前薄弱点明确：主按钮进入智能练习。
- 需要资料补充：主按钮进入课程资源生成。
- 没有学习信号：主按钮进入诊断或拍照解题。

### 数据来源

数据来源和可信度仍保留，但从首屏主视觉降级为推荐依据或页面底部信息，不作为核心操作入口。

## 视觉与交互约束

- 每个页面只保留一个主 CTA。
- 工具入口使用折叠或次级按钮，不与主任务争抢注意力。
- 保留现有 Sky 风格，但减少卡片堆叠和大面积并列入口。
- 删除“队员 B 业务闭环”等内部项目文案。
- 移动端优先显示今日任务、路线当前阶段和主按钮。
- 所有按钮保持至少 44px 高度，保留图标和文字。

## 代码影响范围

首版预期修改：

- `components/sky/layout/sky-tab-bar.tsx`：调整导航文案，使入口更贴近用户任务。
- `app/sky/page.tsx`：将摘星锦囊收敛为今日学习首页。
- `components/sky/learning/workshop-page.tsx`：重编排天梯工坊，移除个性化学习工作台显眼入口，折叠工具矩阵。
- `components/sky/study-lab/study-lab-page.tsx`：删除内部项目文案，降级为隐藏详情页。

不改动后端接口。

## 验收标准

- 用户主导航里不再看到多个含义相近的学习总控入口。
- 摘星锦囊第一屏能明确告诉用户今天该做什么。
- 天梯工坊第一屏能明确展示今日计划和学习路线，而不是工具大杂烩。
- 个性化学习工作台不再作为显眼按钮出现在主流程。
- 原有学习工具仍能通过今日任务、路线节点或更多工具进入。
- 页面不再出现内部开发或队员分工文案。

## 后续演进

如果首版验证后用户路径更清晰，可以继续：

- 将 `/sky/study-lab` 重定向到 `/sky/learning`。
- 把今日任务选择逻辑抽成共享 view model，供首页和天梯工坊共用。
- 为“更多工具”记录点击数据，判断是否需要重新提升某些工具入口。
