# 云端智囊个性化工具方案

> 目标：云端智囊保持“AI 工具集”的定位，不重复天梯工坊的学情驾驶舱；5 个核心工具读取天梯工坊沉淀的学习数据，生成更适合当前学生状态的题目、卡片、讲解、课件和解题反馈。

## 一、边界定义

### 1.1 产品分工

| 模块 | 核心职责 | 不做什么 |
|------|----------|----------|
| 摘星锦囊 | 首页学习概览、快速入口、学习氛围承接 | 不承载具体 AI 生成流程 |
| 天梯工坊 | 学情画像、知识图谱、错题、复习队列、成长路径 | 不把每个 AI 工具的生成面板塞进来 |
| 云端智囊 | AI 工具入口、轻量推荐、个性化生成与教学动作 | 不展示完整薄弱点、正确率、最近记录等驾驶舱信息 |

云端智囊首页只保留：

1. 顶部 Hero。
2. 一条“今日推荐工具”。
3. 5 个核心工具卡片。

完整学情数据仍由天梯工坊承载；云端智囊只消费这些数据，不重复展示。

### 1.2 本阶段范围

保留并个性化 5 个工具：

1. 拍照搜题。
2. PPT课件生成。
3. 智能出题。
4. 记忆卡片。
5. 智能授课。

暂不纳入：

1. 知识库页面入口。
2. 智能写作。
3. 智能翻译。

这些能力可以保留在代码和 API 层，但不进入云端智囊首页工具集，也不作为本阶段个性化重点。

## 二、总体流程

```text
天梯工坊数据
  -> 学生画像 / 错题 / 测验记录 / 复习队列 / 学习路径
  -> PersonalizationContext
  -> 云端智囊工具默认参数
  -> 各工具 Agent prompt 个性化
  -> 生成内容
  -> 答题、复习、学习反馈写回天梯工坊
```

核心原则：

1. 天梯工坊负责“看见学生状态”。
2. 云端智囊负责“基于学生状态行动”。
3. 云端智囊首页不展开学情，只给轻量工具建议。
4. 工具内部可以展示个性化原因，但不做完整数据面板。

## 三、数据契约

新增统一上下文：

```ts
export interface PersonalizationContext {
  userId: string;
  generatedAt: number;
  hasLearningData: boolean;

  weakPoints: Array<{
    knowledgePoint: string;
    mastery: number;
    recentMistakeCount: number;
    actionHref: string;
  }>;

  masteryByKnowledge: Record<string, number>;

  recentAccuracy: number | null;

  dueReviews: Array<{
    id: string;
    kind: 'mistake' | 'memory-card';
    title: string;
    knowledgePoints: string[];
    dueAt: number | null;
    href: string;
  }>;

  errorPatterns: Array<{
    knowledgePoint: string;
    errorType: string;
    frequency: number;
    lastOccurrence: string;
  }>;

  learningPath?: {
    current?: string;
    next?: string;
    nodes: string[];
    reason: string;
  };

  preferredDifficulty: 'easy' | 'medium' | 'hard';

  recommendation: {
    title: string;
    reason: string;
    targetTool: 'solve' | 'slides' | 'quiz' | 'memory' | 'teaching';
    href: string;
  } | null;
}
```

### 3.1 数据来源

| 字段 | 来源 | 现有基础 |
|------|------|----------|
| `weakPoints` | 学生画像、错题、测验记录 | `buildStudentProfile`、`buildCloudMindDashboard` |
| `masteryByKnowledge` | 学生画像 | `StudentProfile.masteryByKnowledge` |
| `recentAccuracy` | 最近测验、画像缓存 | `QuizAttempt.accuracy`、`recentQuizPerformance` |
| `dueReviews` | 错题复习、记忆卡片复习 | `mistakeDAO.getDueForReview`、`memory-due` |
| `errorPatterns` | 错题原因聚合 | `StudentProfile.errorPatterns` |
| `learningPath` | 天梯工坊学习路径 | `/api/sky/learning-path` |
| `preferredDifficulty` | 正确率、掌握度、错误频率推导 | 新增规则函数 |

### 3.2 推荐难度规则

```text
recentAccuracy < 55 或 primaryMastery < 50 -> easy
recentAccuracy 在 55~80 或 primaryMastery 在 50~75 -> medium
recentAccuracy > 80 且 primaryMastery > 75 -> hard
```

如果没有学情数据，默认 `medium`，并优先推荐智能出题做入门诊断。

## 四、API 设计

### 4.1 新增接口

```http
GET /api/sky/cloud-mind/personalization-context
```

返回：

```ts
{
  success: true,
  data: PersonalizationContext
}
```

建议实现方式：

1. 复用 `resolveUserId`。
2. 复用 `buildStudentProfile`。
3. 复用错题 DAO、测验记录 DAO、复习调度数据。
4. 复用或抽取 `buildCloudMindDashboard` 中的推荐逻辑。
5. 增加 `preferredDifficulty` 和 `learningPath` 聚合。

### 4.2 和现有 dashboard 的关系

当前已有：

```http
GET /api/sky/cloud-mind/dashboard
```

建议保留它作为首页轻推荐和兼容层。新增的 `personalization-context` 更偏工具内部消费，字段更完整、更稳定。

推荐分工：

| 接口 | 用途 |
|------|------|
| `/dashboard` | 云端智囊首页轻推荐 |
| `/personalization-context` | 5 个工具内部个性化参数 |

## 五、5 个工具的个性化方案

### 5.1 拍照搜题

个性化输入：

1. 薄弱知识点。
2. 掌握度。
3. 错因模式。
4. 最近正确率。

个性化行为：

1. 解题后自动识别题目知识点是否命中薄弱点。
2. 掌握度低时，优先讲概念和基础步骤。
3. 掌握度高时，补充变式、技巧和易错提醒。
4. 常见错因是计算错误时，增加检查点。
5. 常见错因是概念不清时，增加概念辨析。

输出动作：

1. 生成同类题。
2. 生成记忆卡片。
3. 进入微讲解。
4. 写回错题和学情。

### 5.2 PPT课件生成

个性化输入：

1. 目标主题。
2. 薄弱知识点。
3. 学习路径节点。
4. 班级或个人掌握度。

个性化行为：

1. 课件结构优先覆盖薄弱点。
2. 低掌握度知识点增加例题、图解和随堂检测。
3. 高掌握度知识点压缩为复习或拓展页。
4. 自动生成“易错提醒”“课堂提问”“课后练习”。

输出动作：

1. 保存课件。
2. 生成配套小测。
3. 生成授课讲解。

### 5.3 智能出题

个性化输入：

1. 第一薄弱点。
2. 推荐难度。
3. 错因模式。
4. 最近正确率。

个性化行为：

1. 默认主题来自薄弱点。
2. 默认难度来自 `preferredDifficulty`。
3. 概念错多：增加辨析题、判断题、反例题。
4. 方法错多：增加步骤排序、过程选择题。
5. 计算错多：增加短计算、验算题。

输出动作：

1. 答题记录写回 `quiz_attempts`。
2. 错题进入错题本。
3. 低正确率时推荐生成记忆卡片和微讲解。

### 5.4 记忆卡片

个性化输入：

1. 到期复习。
2. 薄弱知识点。
3. 错题内容。
4. 掌握度。

个性化行为：

1. 自动选择最需要复习的知识点。
2. 生成“概念卡 + 例题卡 + 易错卡”组合。
3. 掌握度低时卡片更短、更基础。
4. 掌握度高时增加迁移题和反例。
5. 根据复习反馈更新下一次复习时间。

输出动作：

1. 提交 `memory-reviews`。
2. 更新掌握度。
3. 回流天梯工坊复习队列。

### 5.5 智能授课

个性化输入：

1. 学习路径。
2. 薄弱知识点。
3. 错因模式。
4. 推荐难度。

个性化行为：

1. 默认讲解主题来自学习路径下一节点或第一薄弱点。
2. 概念不清：先类比，再定义，再例题。
3. 方法错误：拆步骤、给流程图、做一步一问。
4. 计算错误：强调公式代入、单位、验算。
5. 讲解后直接生成 3~5 道小测。

输出动作：

1. 跳转智能出题。
2. 生成记忆卡片。
3. 保存课堂材料。

## 六、前端交互方案

### 6.1 云端智囊首页

首页保持轻量：

```text
Hero
今日推荐工具：建议先用智能出题练二次函数
按钮：开始练习 / 生成记忆卡片
5 个工具卡片
```

不出现：

1. 完整薄弱点列表。
2. 待复习队列。
3. 最近正确率。
4. 最近记录。
5. 大块证据链。

### 6.2 工具卡片轻量个性化

可以在不改变卡片设计的前提下，只改卡片里的小标签或 stats 文案：

| 工具 | 个性化文案示例 |
|------|----------------|
| 拍照搜题 | `可关联薄弱点` |
| PPT课件生成 | `按薄弱点组课` |
| 智能出题 | `推荐：二次函数` |
| 记忆卡片 | `待巩固：3 项` |
| 智能授课 | `适合先讲顶点式` |

注意：只做轻提示，不展示完整数据表。

### 6.3 工具内部

每个工具页顶部增加一个小型个性化提示条：

```text
已根据天梯工坊为你预设：二次函数 / 中等难度 / 概念辨析优先
```

用户可以一键接受，也可以手动改主题和难度。

## 七、模块划分

### 7.1 服务层

| 模块 | 建议位置 | 职责 |
|------|----------|------|
| 个性化上下文构建 | `lib/cloud-mind/personalization-context.ts` | 聚合天梯工坊数据 |
| 推荐难度规则 | `lib/cloud-mind/difficulty-policy.ts` | 根据正确率和掌握度推导难度 |
| 工具参数适配 | `lib/cloud-mind/tool-presets.ts` | 把上下文转成各工具默认参数 |
| prompt 注入 | `lib/agents/cloud-mind/*` | 将个性化信息写入 Agent prompt |

### 7.2 API 层

| API | 职责 |
|-----|------|
| `GET /api/sky/cloud-mind/personalization-context` | 给 5 个工具提供统一个性化上下文 |
| `GET /api/sky/cloud-mind/dashboard` | 只给首页提供轻推荐 |
| `POST /api/sky/cloud-mind/quiz-attempts` | 测验结果写回画像 |
| `POST /api/sky/cloud-mind/memory-reviews` | 记忆卡片复习结果写回画像 |

### 7.3 前端层

| 页面 | 改造点 |
|------|--------|
| `/sky/cloud-mind` | 只展示轻推荐和 5 个工具卡片 |
| `/sky/cloud-mind/quiz` | 自动填入主题、难度、题型倾向 |
| `/sky/cloud-mind/memory` | 自动从薄弱点或错题生成卡片 |
| `/sky/cloud-mind/teaching` | 自动填入微课主题和讲解策略 |
| `/sky/cloud-mind/solve` | 解题后展示个性化后续动作 |
| `/sky/cloud-mind/slides` | 课件结构按薄弱点和学习路径调整 |

## 八、实施路线

### P0：统一上下文

目标：让 5 个工具能读到同一份个性化数据。

任务：

1. 新增 `PersonalizationContext` 类型。
2. 新增 `GET /api/sky/cloud-mind/personalization-context`。
3. 抽取推荐难度规则。
4. 加测试覆盖空学情、有画像、有错题、有测验记录四类场景。

验收：

1. 空学情返回新手默认值。
2. 有学情时返回第一薄弱点、推荐难度、最近正确率。
3. 不依赖知识库、写作、翻译。

### P1：智能出题、记忆卡片、智能授课

目标：先打通最核心的“诊断 -> 练习 -> 复习 -> 讲解”闭环。

任务：

1. 智能出题默认主题和难度来自上下文。
2. 记忆卡片默认主题和内容来自薄弱点或到期复习。
3. 智能授课默认主题来自学习路径或薄弱点。
4. 三个工具页都展示轻量个性化提示条。

验收：

1. 用户不输入主题，也能生成贴合薄弱点的内容。
2. 用户仍可手动覆盖默认值。
3. 测验和复习结果能写回天梯工坊。

### P2：拍照搜题

目标：让解题不只是给答案，而是连接个性化学习动作。

任务：

1. 解题结果识别知识点后对照薄弱点。
2. 根据掌握度调整讲解深度。
3. 输出同类题、卡片、微讲解三个动作。

验收：

1. 命中薄弱点时有明确提示。
2. 不同掌握度看到的讲解策略不同。
3. 后续动作能正确带入题目和知识点。

### P3：PPT课件生成

目标：让课件成为个性化教学材料，而不是平均生成内容。

任务：

1. 课件规划读取薄弱点和掌握度。
2. 低掌握度知识点增加例题和检测。
3. 自动输出课堂提问和课后练习。

验收：

1. 同一主题在不同画像下生成结构不同。
2. 课件包含薄弱点强化页。
3. 可继续生成测验或授课讲解。

## 九、测试方案

### 9.1 单元测试

| 模块 | 测试重点 |
|------|----------|
| `personalization-context` | 数据聚合、空态、有画像、有错题 |
| `difficulty-policy` | 正确率和掌握度到难度的映射 |
| `tool-presets` | 上下文到 5 个工具默认参数的转换 |
| 推荐引擎 | 不把写作、翻译、知识库推荐到首页 |

### 9.2 页面测试

1. 云端智囊首页只显示轻推荐和 5 个工具。
2. 首页不出现待复习队列、完整薄弱点、最近正确率、最近记录。
3. 智能出题页能自动填入推荐主题。
4. 记忆卡片页能自动带入薄弱点。
5. 智能授课页能自动带入微讲解主题。

### 9.3 集成测试

```text
天梯工坊已有薄弱点：二次函数
  -> 进入云端智囊
  -> 今日推荐工具显示智能出题
  -> 进入智能出题，主题自动为二次函数
  -> 完成测验
  -> 错题生成记忆卡片
  -> 复习记录写回天梯工坊
```

## 十、风险与取舍

| 风险 | 说明 | 对策 |
|------|------|------|
| 和天梯工坊重复 | 云端智囊如果展示完整数据，会变成第二个驾驶舱 | 首页只保留轻推荐，完整数据回天梯工坊 |
| 个性化过强 | 用户可能只想临时生成别的内容 | 所有默认值都允许手动覆盖 |
| 数据为空 | 新用户没有画像 | 默认推荐入门诊断 |
| 数据陈旧 | 缓存画像可能不是最新 | 测验和复习后主动失效画像缓存 |
| 工具 prompt 变复杂 | Agent 输出稳定性可能下降 | 用结构化上下文和短字段注入，不塞长数据表 |

## 十一、成功标准

1. 云端智囊首页不再承担学习驾驶舱职责。
2. 5 个工具都能读取同一份个性化上下文。
3. 用户进入工具时至少有一个合理默认参数。
4. 智能出题、记忆卡片、智能授课形成闭环。
5. 测验和复习结果能继续回流天梯工坊。

## 十二、推荐下一步

建议先做 P0 + P1。

原因：

1. P0 建好统一上下文，后续工具都能复用。
2. P1 覆盖智能出题、记忆卡片、智能授课，是最短学习闭环。
3. 不会改变云端智囊首页定位。
4. 不依赖知识库、写作、翻译，符合当前范围收敛。
