# 智能出题 · 提升方案

> 云端智囊六功能之一。短板核心 = "只会选择题 + 一点都不攒"（AI 生完即弃、不入库），以及答题无订正闭环。

## 0. 一句话定位
底层 `question_bank` 表已支持 choice/fill/solve/judge **四题型**，上层却只认真做了选择题。让生成结果"先会出更多题型、再回填题库攒资产"，是让系统"越用越厚"的关键。

## 1. 现状
- AI 生成选择题 + 题库抽题两种模式；学科/难度/知识点/数量选择；答题后写学情。
- 个性化参数推导 + RAG 检索 + 学情注入；LLM 多层容错；in-memory 缓存（TTL 10min/100 条/重试×1）。
- 底层表四题型已就绪，上层只做了 choice。

## 2. 短板与取舍
| 优先级 | 事项 | 说明 |
|---|---|---|
| P0 | 接上填空/判断题型 | 底层表已支持，上层未接；简答 AI 判分不稳可后置。与搜题/题库自沉淀联动 |
| P0 | AI 生成成功后回填题库 | 现生完即弃不攒资产；回填后可复用。需去重 + "生成题/标准题"区分标记 |
| P1 | 答题订正闭环：答错→看解析/进错题本/衔接复习 | 复用搜题/记忆卡已有的错题本+下一步基建，低成本高收益 |
| P1 | 出题输出套 Zod schema 校验 | 现只有 try/catch+手动修复；符合项目 Zod runtime validation 规范 |
| P2 | 公式渲染收敛 | 出题用自带 `solve/math-renderer.tsx`（带 LRU），与 PPT/记忆卡的 InlineMath 不一致 → 统一到公式共享专项 |
| P2 | 缓存粗糙 | 相同 topic 二次返回旧缓存、无 freshness；暂不优先（但属正确性隐患，配合缓存统一层处理） |

> 联动：出题、搜题成功结果共用 `question_bank` 表，双边命中互相喂养（"题库越用越厚"机制）。

## 3. 优先级行动
| 优先级 | 事项 |
|---|---|
| P0 | 填空 / 判断题型接入（复用底层表） |
| P0 | AI 出题成功回填题库（去重 + 题型标记） |
| P1 | 答题订正闭环（答错 → 解析/错题本/复习衔接） |
| P1 | 输出套 Zod schema 校验 |
| P2 | 公式渲染收敛到共享组件 |

## 4. 测试方法
- **题型（组件+API）**：选填空/判断题 → 生成并渲染对应题型，字段齐全（填空：题干+标准答案；判断：题干+正误）。
- **入库（自动）**：出题成功后查 `question_bank` 断言新题入库且带题型/知识点；同题重复出仅 1 条（去重）。
- **入库去重（自动）**：重复 topic 再生成，assertEquals 不产生重复题；"生成题/标准题"标记正确区分。
- **订正闭环（组件）**：答错 → 展示解析 + 一键进错题本 + 链接复习/再练。
- **Zod 校验（单测）**：mock LLM 返回残缺/错型 JSON → 被 schema 拦下并重试，不产出结构错误题。
- **正确性回归**：`cloud-mind-quiz-*.test` 等既有用例不回归。

### 回归测试清单（下次迭代仍按此执行）

### A. 题型选择与生成（P0）
1. 进入页面 → 出题模式默认「AI 出题」→「题型选择」面板出现 选择题 / 填空题 / 判断题 三个入口。
2. 选「填空题」→ 配 3 题 → 生成：题目卡片为输入框 + 「提交答案」；提交后展示「标准答案」与「我答对了 / 我答错了 / 跳过自评」。
3. 选「判断题」→ 生成：答题选项仅「正确 / 错误」两项，点选后高亮对错。
4. 选「选择题」→ 回归验证：仍为四选一、答后即时对错反馈。
5. 同配置连点两次生成，两次题型渲染一致（缓存命中不改变 UI 结构）。

### B. 题库自动沉淀（P0）
6. 填空题 3 题生成并完成作答 → 结果页出现「题库自动沉淀」提示，显示新增 3 题。
7. 访问题库页（星域题库）→ 按学科/难度过滤能看到刚才的 3 道填空题，`source`=AI 智能出题、带「AI生成 / 生成题」标记。
8. 用完全相同配置（学科/难度/知识点/数量/题型）再次生成 → 提示「跳过重复 3 题」，题库中该批题仍只有 1 份（去重生效）。
9. 生成过程中断/失败 → 不出现沉淀提示且题库无脏数据（回填失败不影响出题结果）。

### C. 答题与订正闭环（P1 回归）
10. 判断题答错 → 展示解析 + 结果页错题可加入错题本/复习计划（原闭环不回归）。
11. 填空题「跳过自评」→ 不记录对错，结果页该题不误判。
12. 结果页填空题展示「你的答案（用户输入内容）· 正确答案（标准答案文本）」而非 undefined。

### D. 数据一致性
13. 后端 `question_bank` 表：抽查新题的 `question_type`、`knowledge_points`、`tags` JSON、`problem_hash` 唯一性。
14. 题库抽题模式（非 AI 出题）不受影响：仍按条件抽选择题、数量不足提示照旧。
