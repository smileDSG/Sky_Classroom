# 软件杯截图与录屏清单

## 必拍页面

1. `/sky/software-cup` 工作台整体页面。
2. 自然语言输入区与 8 维学习画像。
3. 多智能体协同进度面板。
4. 《人工智能导论》课程知识库命中结果。
5. 6 类个性化资源卡片。
6. 两周学习路径与推荐理由。
7. 安全与防幻觉审核面板。
8. 开源说明文档与第三方许可说明。

## 建议录屏流程

1. 打开 `/sky/software-cup`。
2. 点击“演示输入”。
3. 点击“运行闭环”。
4. 依次展示画像、Agent 进度、课程命中、资源卡片、学习路径和审核结果。
5. 简短展示 `data/course-knowledge/ai-intro/` 目录，说明完整课程知识库。
6. 打开 `OPEN_SOURCE_NOTICE.md` 和 `docs/software-cup-safety-and-trust.md`，说明合规和可信机制。

## 验收截图对应关系

| 截图 | 对应赛题要求 |
| --- | --- |
| 画像面板 | 对话式学习画像，不少于 6 维 |
| Agent 进度 | 多智能体协作架构 |
| 资源卡片 | 至少 5 类个性化资源 |
| 学习路径 | 个性化路径规划与资源推送 |
| 审核面板 | 防幻觉与内容安全 |
| 课程目录 | 至少一门完整高校课程知识库 |
| 开源说明 | 开源项目和协议显著标注 |
