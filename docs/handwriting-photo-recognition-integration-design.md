# 手写纸质照片识别与拍照搜题融合设计

> 状态：方案已确认，待拆分实施计划
> 日期：2026-07-22

## 目标

在现有 `/sky/cloud-mind/solve` 拍照搜题页面中，增强纸质手写照片的文字与数学公式识别能力。保持现有前端页面、布局和交互风格不变，识别结果继续进入已有的解题 Agent、验证、置信度、错题本和学情画像流程。

本期不新增独立的手写作业页面，不实现独立的手写提交/批改工作流，也不改变现有解题结果展示。

## 现状与边界

- 入口页面：`app/sky/cloud-mind/solve/page.tsx`
- 主要交互：`components/sky/solve/solve-page.tsx`
- 图片输入：`components/sky/solve/multimodal-input.tsx`
- 识别接口：`app/api/sky/solve/recognize/route.ts`
- 识别辅助：`lib/recognition/image-validator.ts`、`formula-extractor.ts`、`problem-spec-parser.ts`
- 现有识别接口已经支持视觉模型回退、公式提取和结构化题目输出；需要将提示词和结果处理调整为“印刷体/手写体自适应转录”，而不是只面向标准印刷题目。

## 用户流程

```text
用户在现有拍照搜题页面上传纸质照片
    ↓
现有图片校验与预览
    ↓
手写/印刷混合识别，输出文字、LaTeX、置信度和模糊说明
    ↓
复用现有识别结果区域供用户确认或修改
    ↓
确认后的文本进入现有解题流程
    ↓
继续使用现有解题 Agent、验证、置信度、错题本和学情画像逻辑
```

## 识别 API 设计

保持 `POST /api/sky/solve/recognize` 路径和现有图片上传方式不变。

视觉提示词必须支持中文手写、英文手写、数字、单位、数学公式、手写与印刷混排、题号、分行、选项、表格、图形标签；无法确认的字符使用占位标记并记录歧义，不猜测；公式统一转换为 LaTeX；输出置信度，并按低置信度结果阻止自动进入解题。

保留现有字段：`text`、`latex`、`problemCount`、`problems`、`structuredProblems`、`usedModel`。

新增可选字段：

- `confidence: number`
- `ambiguities: { text: string; candidates: string[]; reason: string }[]`
- `needsConfirmation: boolean`

现有前端只读取旧字段时仍能正常工作；增强后的前端可以使用新字段显示确认提示。

## 前端设计

不改变当前页面的视觉结构和主要组件。只在现有识别结果区域增加识别置信度提示、低置信度/歧义重拍提示，并允许用户修改识别文本后继续解题。现有拍照、拖拽、粘贴、预览和解题按钮保持不变。

## 错误处理

- 图片模糊、过暗、反光或裁切不足：沿用现有图片校验错误，并提示重拍。
- 识别结果为空：保留原图，允许重新识别。
- 公式或字符存在歧义：显示可编辑结果，不自动进入解题。
- 视觉模型失败：沿用现有多模型回退和错误响应。
- 所有模型失败：不污染解题、错题本或学情画像数据。

## 测试策略

增加识别 API 和组件测试，覆盖清晰手写中文与数字、手写数学公式与单位、手写/印刷混合图片、低置信度和歧义结果、识别结果确认后进入现有解题调用，以及既有印刷体识别回归。使用现有 `tests/recognition/recognize-api.test.ts` 和拍照搜题组件测试作为主要测试入口。

## 非目标

- 不实现手写作业独立提交页面
- 不实现手写作业独立评分 Agent
- 不新增教师复核后台
- 不改变现有拍照搜题页面整体样式
- 不删除已合入的 `lib/handwriting` 基础模块，但本期不把它作为识别入口
