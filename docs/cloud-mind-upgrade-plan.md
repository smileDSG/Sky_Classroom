# 云端智囊总体升级方案

> 目标：将云端智囊从“AI 工具集合”升级为“个人学习中枢”，把搜题、出题、记忆卡、课件、授课、写作、翻译、知识库和学情画像串成可解释、可沉淀、可持续优化的学习闭环。

## 一、现状概览

### 1.1 当前功能版图

云端智囊相关功能主要分布在以下路径：

| 类型 | 路径 | 当前能力 |
|------|------|----------|
| 总览页 | `app/sky/cloud-mind/page.tsx` | 展示拍照搜题、PPT 课件生成、智能出题、记忆卡片、智能授课 |
| 首页入口 | `components/sky/home/cloud-mind-hero-button.tsx` | 首页快速入口，但部分跳转仍指向 `/sky/slides`、`/sky/solve` 等旧路径 |
| 拍照搜题 | `app/sky/cloud-mind/solve/page.tsx` | 复用 `SolvePage`，支持题目识别、解析、错题沉淀 |
| PPT 课件 | `app/sky/cloud-mind/slides/page.tsx` | 复用课件生成页，已有较成熟的生成、封面、预览和导出链路 |
| 智能出题 | `app/sky/cloud-mind/quiz/page.tsx` | 支持 AI 出题、题库抽题、答题、成绩写入学情、AI 题加入题库 |
| 记忆卡片 | `app/sky/cloud-mind/memory/page.tsx` | 支持手动输入、从错题导入、基于薄弱点自动生成卡片 |
| 智能授课 | `app/sky/cloud-mind/teaching/page.tsx` | 复用授课页面，面向讲解方案和课堂内容生成 |
| 智能写作 | `app/sky/cloud-mind/write/page.tsx` | 已实现流式写作，但未进入总览页工具矩阵 |
| 智能翻译 | `app/sky/cloud-mind/translate/page.tsx` | 已实现翻译、备选翻译和说明，但未进入总览页工具矩阵 |
| 知识库接口 | `app/api/sky/cloud-mind/knowledge/route.ts` | 支持上传、查询、删除 RAG 文档，当前偏接口能力 |
| 生成 Agent | `lib/agents/cloud-mind/*` | 包含出题、记忆卡、写作、翻译、课件分析等 Agent |

### 1.2 已有优势

1. 多个核心学习工具已经存在，不需要从零开始。
2. 智能出题已经接入学情画像，并能保存答题记录。
3. 记忆卡已经支持从错题导入，并能基于薄弱点自动生成。
4. 写作和翻译结果已经可以跳转生成记忆卡，具备初步跨工具流转能力。
5. 课件生成模块已有较强的生成、预览、导出和视觉表现基础。
6. 知识库、RAG、学生画像、错题、题库等底层能力已经具备雏形。

### 1.3 主要问题

| 问题 | 表现 | 影响 |
|------|------|------|
| 功能入口不完整 | 写作、翻译存在页面但未出现在总览页 | 用户发现成本高，产品完整度显得不足 |
| 路由不统一 | 首页入口部分跳转到 `/sky/slides`、`/sky/solve`、`/sky/assistant` | 云端智囊品牌感被削弱 |
| 工具仍偏孤岛 | 每个工具能用，但跨工具衔接多靠按钮跳转 | 难形成“系统懂我”的学习体验 |
| 知识库不可见 | 有 RAG 接口和检索逻辑，但缺少可操作的资料库页面 | AI 输出可信度不足，引用来源不可解释 |
| 记忆卡进度偏临时 | `studiedCards` 主要是页面状态 | 复习计划、间隔重复和长期掌握度无法闭环 |
| 生成质量缺少统一 QA | 出题有一定格式修复，其他 Agent 缺少质量检查层 | AI 内容稳定性与教学可信度不足 |
| 总览页偏工具箱 | 目前主要是功能卡片 | 缺少“今天该学什么”的主动指导 |

## 二、升级目标

### 2.1 产品定位

升级后的云端智囊定位为：

> 一个围绕学生画像持续运转的 AI 学习中枢。它能诊断薄弱点，生成学习材料，组织练习与复习，解释推荐依据，并把每次学习结果继续沉淀回学生画像。

### 2.2 核心目标

1. 统一入口：所有云端智囊能力收敛到 `/sky/cloud-mind/*`。
2. 建立闭环：形成“诊断 -> 学习 -> 练习 -> 反馈 -> 复习 -> 再诊断”的完整路径。
3. 可信可解释：AI 推荐和生成内容都能展示依据、引用来源、相关错题或学情证据。
4. 结果可沉淀：所有 AI 生成结果都能保存到题库、知识库、记忆卡、课堂素材或学习报告。
5. 质量可控：为各 Agent 增加结构化校验和教学质量自检。
6. 兼顾学生与教师：学生端强调个性化学习，教师端强调班级诊断、分层练习和课堂备课。

### 2.3 成功指标

| 指标 | 目标 |
|------|------|
| 功能发现 | 总览页覆盖所有已有云端智囊工具 |
| 学习闭环 | 用户能从一次错题进入讲解、练习、记忆卡和复习计划 |
| 个性化 | 出题、记忆卡、授课、写作至少 4 类工具能读取学生画像 |
| 可解释 | 智囊推荐展示至少 2 类证据，例如错题、掌握度、到期卡片、引用资料 |
| 沉淀 | AI 生成题目、卡片、写作材料、翻译词汇、课件摘要支持保存 |
| 质量 | Agent 输出结构校验失败时可重试或给出明确错误 |

### 3.2 推荐数据流

```text
学生行为
  -> 搜题 / 答题 / 翻卡 / 写作 / 翻译 / 授课学习
  -> 学习事件 LearningEvent
  -> 错题、题库、记忆卡、知识库、学习记录
  -> 学生画像 StudentProfile
  -> 今日建议 LearningRecommendation
  -> 生成讲解、练习、记忆卡、复习计划
  -> 新一轮学习行为
```

### 3.3 一键学习流

建议新增“开始今日智囊计划”主流程：

1. 读取学生画像、错题、测验记录、记忆卡到期情况。
2. 选择一个最高优先级薄弱知识点。
3. 给出推荐理由和证据链。
4. 生成 3 分钟微讲解。
5. 生成 5 道专项练习题。
6. 学生答题后写入学情。
7. 针对错题生成记忆卡。
8. 安排下一次复习。

这个流程适合比赛演示，因为它能把多个已有模块串成一个完整故事。

## 四、功能升级方案

### 4.1 智囊总览驾驶舱

#### 现状

总览页主要展示工具卡片。它能帮助用户进入功能，但没有主动给出学习建议。

#### 升级内容

1. 补齐工具入口：
   - 拍照搜题
   - PPT 课件生成
   - 智能出题
   - 记忆卡片
   - 智能授课
   - 智能写作
   - 智能翻译
   - 知识库

2. 增加今日驾驶舱：
   - 今日建议学习点
   - 推荐原因
   - 待复习卡片数量
   - 最近高频错因
   - 最近生成内容
   - 快捷动作

3. 增加“开始今日智囊计划”：
   - 自动生成学习路径
   - 串联讲解、练习、记忆卡
   - 最后展示掌握度变化

#### 建议页面结构

```text
/sky/cloud-mind
├─ 顶部：今日智囊建议
├─ 中部：一键学习计划
├─ 左侧：薄弱点与证据链
├─ 右侧：待复习与最近记录
└─ 底部：全部工具矩阵
```

### 4.2 学业诊断官

#### 目标

让搜题、出题、题库、错题和学情画像形成闭环。

#### 升级内容

1. 搜题后自动识别知识点和错因。
2. 解析页提供三个动作：
   - 生成同类题
   - 加入记忆卡
   - 进入微讲解
3. 测验结束后输出学习诊断：
   - 正确率
   - 错题知识点
   - 高频错因
   - 建议下一步
4. 对连续薄弱知识点自动推荐专项练习。
5. 题库抽题和 AI 出题统一进入答题记录。

#### 推荐动作规则

| 条件 | 推荐动作 |
|------|----------|
| 某知识点 7 天内错题数大于 2 | 生成专项练习 |
| 某知识点正确率低于 60% | 生成微讲解 |
| 答对但耗时较长 | 标记为“不熟练”，安排复习 |
| 同一错因连续出现 | 生成错因专项训练 |
| 测验正确率高于 85% | 推荐提高难度 |

### 4.3 知识炼金师

#### 目标

把写作、翻译、记忆卡和知识库变成学习材料沉淀系统。

#### 记忆卡升级

1. 为每张卡片增加长期复习状态：
   - `mastery`
   - `reviewCount`
   - `lastReviewedAt`
   - `nextReviewAt`
   - `sourceType`
   - `sourceId`
2. 翻卡后增加反馈：
   - 已掌握
   - 模糊
   - 没记住
3. 根据反馈调整复习间隔。
4. 到期卡片出现在云端智囊总览页。
5. 从错题生成的卡片反向关联原错题。

#### 写作升级

1. 从“生成作文”升级为“写作教练”：
   - 提纲生成
   - 范文生成
   - 结构点评
   - 语言润色
   - 评分量表
   - 可改写版本
2. 写作结果可沉淀：
   - 保存为素材
   - 生成记忆卡
   - 加入知识库
   - 形成写作报告

#### 翻译升级

1. 从“翻译文本”升级为“语言学习”：
   - 逐句对照
   - 关键词汇
   - 语法点解释
   - 备选表达
   - 语气风格说明
2. 翻译结果可沉淀：
   - 词汇卡
   - 句型卡
   - 双语素材
   - 翻译知识库

#### 知识库升级

1. 新增 `/sky/cloud-mind/knowledge` 页面。
2. 支持资料上传、文本粘贴、课堂材料保存。
3. 支持资料类型：
   - 教材
   - 课堂笔记
   - 错题解析
   - 记忆卡片
   - 写作素材
   - 翻译词汇
   - 课件摘要
4. AI 输出展示引用来源。
5. 统一内存 RAG 与持久化知识库的生命周期，优先使用 `lib/knowledge-base/kb-manager.ts` 作为长期底座。

### 4.4 课堂设计师

#### 目标

让云端智囊不仅服务学生自学，也能服务教师备课和课堂设计。

#### PPT 课件升级

1. 生成前根据学生画像推荐课件难度。
2. 支持从知识库选择资料生成课件。
3. 生成后自动输出：
   - 讲解稿
   - 课堂提问
   - 随堂测验
   - 课后作业
4. 导出时附带学习目标和知识点清单。

#### 智能授课升级

1. 支持按薄弱点生成 3 分钟微课。
2. 支持“讲完马上测”。
3. 支持把授课内容保存为知识库和记忆卡。
4. 支持按班级薄弱点生成教师讲解方案。

### 4.5 学习证据链

#### 目标

让 AI 推荐可解释，避免黑盒感。

#### 证据类型

| 证据 | 来源 |
|------|------|
| 错题证据 | 错题本、搜题记录、测验记录 |
| 掌握度证据 | 学生画像、知识图谱 |
| 复习证据 | 记忆卡片到期状态 |
| 资料证据 | 知识库引用来源 |
| 行为证据 | 学习时长、答题耗时、最近学习记录 |

#### 展示示例

```text
建议复习：二次函数顶点式

推荐依据：
1. 最近 7 天相关题目 5 题错 3 题
2. “二次函数”掌握度为 48
3. 有 4 张相关记忆卡今天到期
4. 本次讲解参考了《函数专题复习》中的第 2、3 个片段
```

## 五、数据定义

### 5.1 LearningEvent

记录学生在云端智囊中的所有关键行为。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 事件 ID |
| `userId` | string | 用户 ID |
| `type` | string | 事件类型，例如 quiz_completed、card_reviewed、solve_completed |
| `source` | string | 来源工具，例如 quiz、memory、solve、write |
| `subject` | string | 学科 |
| `knowledgePoints` | string[] | 关联知识点 |
| `payload` | object | 事件详情 |
| `createdAt` | string | 创建时间 |

### 5.2 LearningRecommendation

总览页今日建议。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 推荐 ID |
| `title` | string | 推荐标题 |
| `reason` | string | 简短原因 |
| `priority` | number | 优先级 |
| `actionType` | string | 推荐动作，例如 start_plan、review_cards、practice_quiz |
| `target` | object | 跳转目标或执行参数 |
| `evidence` | EvidenceItem[] | 证据链 |

### 5.3 EvidenceItem

推荐和生成结果的证据项。

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | mistake、profile、memory、knowledge、behavior |
| `title` | string | 证据标题 |
| `summary` | string | 证据摘要 |
| `sourceId` | string | 来源记录 ID |
| `confidence` | number | 置信度，可选 |

### 5.4 MemoryCardReview

记忆卡长期复习记录。

| 字段 | 类型 | 说明 |
|------|------|------|
| `cardId` | string | 卡片 ID |
| `deckId` | string | 卡组 ID |
| `userId` | string | 用户 ID |
| `rating` | string | remembered、fuzzy、forgotten |
| `reviewCount` | number | 复习次数 |
| `mastery` | number | 掌握度 |
| `lastReviewedAt` | string | 上次复习时间 |
| `nextReviewAt` | string | 下次复习时间 |

### 5.5 AgentQualityReport

Agent 输出质量报告。

| 字段 | 类型 | 说明 |
|------|------|------|
| `agentType` | string | quiz、memory、write、translate、slides |
| `pass` | boolean | 是否通过 |
| `score` | number | 质量分 |
| `issues` | object[] | 问题列表 |
| `suggestedFix` | string | 修复建议 |

## 七、阶段路线图

### 阶段 0：入口统一与功能补齐

目标：解决“已有功能不可见”和“路径不统一”的问题。

任务：

1. 将写作、翻译加入云端智囊总览页工具矩阵。

## 九、风险与对策

| 风险 | 说明 | 对策 |
|------|------|------|
| 功能过多导致开发发散 | 云端智囊覆盖模块多 | 按阶段推进，先做闭环主线 |
| AI 输出不稳定 | LLM 可能返回格式错误或内容质量波动 | 增加结构化 schema、质量检查和重试 |
| 知识库双轨 | 内存 RAG 与持久化 KB 同时存在 | 统一知识库生命周期，保留内存检索作为缓存 |
| 学生画像过度依赖历史数据 | 新用户没有数据 | 提供新手诊断和默认推荐 |
| 页面复杂度上升 | 总览页容易信息过载 | 使用“今日建议优先，工具入口其次”的布局 |
| 数据隐私 | 学情、错题和资料都属于敏感学习数据 | 明确用户隔离、权限控制和删除能力 |

## 十三、2026-06-25 性能加速落地记录

本次优化先处理云端智囊中最容易形成等待感的 AI 调用链路，目标是在不改变页面交互和 API 返回结构的前提下缩短重复请求与排队等待时间。

### 13.1 已落地

1. 新增 `lib/agents/cloud-mind/cache.ts`，提供云端智囊专用的内存缓存能力。
2. `quiz-agent`、`memory-cards-agent`、`slides-agent` 的已解析成功结果会写入缓存；相同输入再次请求时直接返回缓存结果，跳过模型生成。
3. `quiz-agent`、`memory-cards-agent`、`slides-agent`、`translate-agent`、`write-agent` 已从直接调用 Vercel AI SDK 改为走统一 `callLLM` / `streamLLM` 层。
4. 统一 LLM 层带来的收益包括：多 key 池、限流轮换、超时控制、thinking 配置注入、性能监控记录。
5. 记忆卡片生成根据请求的 `cardCount` 动态控制 `maxOutputTokens`，避免少量卡片也使用 8192 token 上限。
6. 翻译 Agent 文件恢复为正常中文提示词，并修复目标语言变量未插值的问题。

### 13.2 当前边界

1. 缓存是进程内缓存，适合开发环境和单实例部署；多实例生产环境需要迁移到 Redis 或持久化缓存。
2. 缓存只保存成功解析和校验后的结构化结果，不缓存失败响应。
3. 当前仍保留原页面交互：出题、记忆卡片、PPT 分析的非流式接口结构未改变，避免影响前端状态机。
4. 搜题解题链路已有题库、solve cache、SSE 和后台任务，本次未重复改造。

### 13.3 下一步建议

1. 为出题增加分批流式模式：先生成题干和选项，再逐题补解析。
2. 为记忆卡片增加逐卡片流式模式：前端拿到第一批卡片即可开始学习。
3. 为 PPT 长文本分析增加切片摘要：先做章节摘要，再生成讲解脚本。
4. 将云端智囊缓存抽象到 Redis，并按用户、模型、提示词版本、输入 hash 做隔离。
5. 为缓存命中率、首 token 时间、总生成时间增加可观测指标。
