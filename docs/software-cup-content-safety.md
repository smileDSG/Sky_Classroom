# 内容安全策略说明

## 目标

系统面向大学生学习场景，内容安全策略需要同时保护学生、课程内容和生成结果的可信度。系统不只做敏感词过滤，还要结合请求意图、学习场景和输出影响进行判断。

## 输入安全检查

输入阶段识别以下风险：

- 违法违规、暴力、色情、仇恨歧视。
- 个人隐私泄露，如身份证、手机号、住址、学生成绩明细。
- 学术作弊，如“直接帮我写可提交论文/作业/实验报告”。
- 高风险建议，如医疗、法律、金融的确定性建议。
- 诱导模型绕过安全机制或伪造来源。

## 输出安全检查

输出阶段检查：

- 是否包含未脱敏个人信息。
- 是否包含无来源学术断言。
- 是否给出过度确定的结论。
- 是否诱导学生直接提交 AI 生成内容。
- 是否存在偏见、歧视或不恰当表达。

## 处理策略

| 风险类型 | 处理方式 | 示例 |
| --- | --- | --- |
| 学术作弊 | 拒绝代写，转为学习辅导 | 提供提纲、思路、检查清单 |
| 无来源事实 | 标记低置信度或要求补充资料 | “当前知识库无可靠来源” |
| 隐私数据 | 提醒删除或脱敏 | “请不要输入身份证号或手机号” |
| 敏感违规 | 拒答并说明边界 | “该请求不适合提供帮助” |
| 高风险专业建议 | 提醒咨询专业人士 | 不给确定性医疗/法律/金融结论 |

## 学习场景的改写模板

### 代写请求

拒绝直接生成可提交成稿，改为：

- 解释相关概念。
- 提供结构大纲。
- 推荐阅读资料。
- 给出自查问题。
- 帮助检查学生自己的草稿。

### 低置信度问题

如果课程知识库没有可靠来源：

```text
当前课程知识库没有找到足够可靠的来源。我可以先给出需要查证的思路，但不会把它作为确定事实。建议补充教材、课堂资料或教师说明后再生成正式学习资源。
```

### 隐私输入

```text
这段输入可能包含个人隐私。建议删除或脱敏后再继续，例如只保留学习目标、课程名称和薄弱知识点。
```

## 与防幻觉机制的关系

内容安全负责判断“能不能答、应该怎样答”，防幻觉机制负责判断“答得是否有来源、是否可信”。两者共同作用：

- 安全过滤先拦截高风险请求。
- RAG 检索提供课程来源。
- 事实核验 Agent 检查输出。
- 低置信度结果进入人工复核。

## 验收点

该策略覆盖赛题要求中的“内容安全过滤机制”，并能与 `docs/software-cup-safety-and-trust.md` 中的防幻觉机制配合展示。
