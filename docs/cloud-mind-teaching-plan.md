# 智能授课 · 提升方案

> 云端智囊六功能之一。**定位定论**：与主页课堂（B）不重复，是"生成→播放"上下游。A 不该去够"沉浸"，该把 A→B 衔接做顺。

## 0. 一句话定位
骨架强、测试全，短板在**不像在"上课"**——但"上课沉浸"是主页课堂的主场，A 的正解是做好"个人化微课入口 + 一键转到沉浸课堂"。

## 1. 现状（定位定论）
- **A = 个人化逐章微课**：逐章卡片阅读、云端智囊画像驱动难度/节奏、learning path、按钮式 TTS。独立教学引擎（前置诊断 → 计划 → 并发生成章节 → to-classroom 转换）。
- **B = 主页课堂/教室**（`app/classroom/[id]`）= LangGraph 多智能体协作课堂（AI 老师/同学对话讨论、白板、slide/quiz/interactive/PBL、播放状态机、**内置连读 TTS**）。
- **A→B 转换已存在**：A 完成后"转为课堂模式"（`lib/teaching/to-classroom.ts`：chunk→slide）进 B。→ A 为 B 提供内容，B 是 A 的播放出口。
- A 独有：个人化微课 + 智能诊断 + learning path；B 独有：沉浸多智能体协作。

## 2. 短板与取舍
| 优先级 | 事项 | 说明 |
|---|---|---|
| P0 | **A→B 衔接做顺**（一键无感、转换稳定） | A 的变现出口；用 B 的连读 TTS+沉浸课堂替代"给 A 堆自动连读"的错误建议 |
| P1 | 随堂自动发问的平台化 | "讲完测完衔接"，借错题本/下一步基建；A 内轻量加 |
| P1 | 授课页 UI 直接测试补缺 | `TeachingPage`/`TeachingPanel` 无直接测试；后端 `tests/teaching/` 15 个已较好 |
| P2 | 知识库 RAG 内容深挖 | 现无显式 RAG，内容靠画像+模板 prompt；后置专项，可借鉴资源工坊素材 |

> "自动连读配音"不列入 A——那是 B 已做好的主场，A 做反而功能重复。

## 3. 优先级行动
| 优先级 | 事项 |
|---|---|
| P0 | A→B 一键转课堂做顺（默认入口、转换稳定、结果可用） |
| P1 | 块尾自动发问 + 基于作答调整后续内容 |
| P1 | 授课页 UI 测试补缺 |
| P2 | RAG 内容深挖（供给源可接资源工坊） |

## 4. 测试方法
- **A→B 转换（自动+人工）**：任一教案点"转为课堂模式"→ 生成 B 的 slide 场景，章节、测验、公式完整；重定向到 `/classroom/{id}` 可播放；转换失败不丢教案、可重试。
- **页面交互（补测）**：启动授课 → 进度%、失败章节自动重试+手动重试、历史星图回看可用。
- **随堂发问（组件）**：块尾自动触发 quiz，作答后学情回流并衔接下一块。
- **回归（自动）**：`tests/teaching/` 15 个既有用例不回归。
