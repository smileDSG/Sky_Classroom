# 记忆卡片 · 提升方案

> 云端智囊六功能之一。骨架与个性化比预期成熟，缺的是"等待感 + 主动提醒 + 渲染 + 算法没测死"。公式渲染问题为共享基建，详见第四节点。

## 0. 一句话定位
闭环能力（SRS）其实全有，但 **"复习闭环没被推到位 + 首屏太慢 + 手机端渲染糙 + 算法裸奔"** 拖住体验。学生每次打开都看卡面，渲染优先级被低估。

## 1. 现状
- **完整 SRS 间隔重复**：翻卡选"已掌握/还需复习/没记住"，熟练度 ±18/+6，算下次间隔，写 `cloud_mind_memory_reviews`，due 到期出复习入口。
- **个性化几乎全通**：生成前基于薄弱点/到期项/画像预填，注入教学投影。
- 错题本导入、桌面 + 移动双端页面齐备。

## 2. 短板与取舍
| 优先级 | 事项 | 说明 |
|---|---|---|
| P0 | 移动端：3D 翻卡 + 接公式渲染 + 修长文本溢出 | 现手机端只有正反文本切换、不接 KaTeX（公式显示原文）、`min-h-[260px]` 固定高度长内容被裁 |
| P0 | 首卡流式/分批生成 | 一次等全量、60s 超时即失败——最伤留存 |
| P1 | 桌面端：修 `overflow-hidden` 翻转裁切隐患 + 标签 `text-[10px]` 字号 | 3D 翻转与 backfaceVisibility 叠外层 overflow 易裁切 |
| P1 | 到期主动提示（页面顶部"今天 XX 张待复习"） | 现要手动打开才复习，闭环没被推到位 |
| P1 | 给 `spaced-repetition.ts`/`memory-cards-agent.ts` 补算法单测 | 现无独立测试，算法裸奔是闷雷 |
| 低 | `cache.ts` 进程内内存缓存重启即丢 | 学生内容互异，命中非关键，暂不动 |

> 公式渲染细节（桌面 P0 的"红字报错/块撑爆/移动缺接"）在共享笔记第四节，本文不再重复。

## 3. 优先级行动
| 优先级 | 事项 |
|---|---|
| P0 | 移动端翻卡 + 公式 + 溢出三修（桌面端小修裁切/字号） |
| P0 | 首卡流式/分批（≤3s 出第一张，性能基线） |
| P1 | 到期复习主动提示 |
| P1 | SRS 算法补单测 |

## 4. 测试方法
- **渲染（桌面+移动，自动+截图）**：
  - 移动端翻卡与桌面端一致的翻转动画生效；公式在移动端经 KaTeX 渲染而非显示 `$..$` 原文。
  - 长答案（>3 屏）在桌面端滚动区、移动端不溢出不裁剪。
  - 桌面端 A/B：翻转过程无边缘裁切/重影；标签可读（非 10px）。
  - 深浅模式切换后卡片文字/标签可读（移动端暗色对比不足需验）。
- **流式（自动）**：mock LLM 分批返回，断言 ≤3s 出第一张；中断时已出卡不丢、失败可重试而非整副失败。
- **SRS 算法（自动单测）**：记忆反馈 remembered/fuzzy/forgotten → 熟练度 ±18/+6、下次间隔正确；到期 `due` 判定正确；持久化到 reviews 表后可查询。
- **主动提醒（组件测试）**：存在到期卡时页面顶部显示"今天 N 张待复习"，无到期卡时不显示。
