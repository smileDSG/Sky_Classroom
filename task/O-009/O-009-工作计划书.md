# O-009 虚拟形象创建 实施方案

> 负责人：队员3 / 日期：2026-05-20 / 基于 API_DEVELOPMENT_PLAN.md Phase 3 优化

---

## Context

队员3 已完成 Module C API（C-001~C-005，14/14 文件，178 用例全部通过）。下一步是实现 O-009 虚拟形象创建。

O-009 目标：用户可在天空课堂中**选择预设头像 / 上传自定义头像 / AI 生成头像**，头像在全局显示（顶栏、AI 对话、聊天消息），AI 助手感知用户昵称。

---

## 关键发现（调研结果）

### 已有基础（直接复用）

| 现有模块 | 复用方式 |
|----------|---------|
| `lib/store/user-profile.ts` — Zustand persist store（avatar/nickname/bio） | 单一数据源，不改结构 |
| `components/user-profile.tsx` — 预设选择 + 上传裁剪（FileReader→Canvas 128x128→dataURL） | 参考实现，复用上传逻辑 |
| `POST /api/generate/image` — AI 图像生成（prompt→image） | 直接调用，不需新 API |
| `public/avatars/` — 30 个头像文件（13 PNG + 17 SVG） | 作为预设选项 |
| `components/sky/layout/app-shell.tsx` — 全局布局壳 | 替换顶栏占位符 |
| `components/sky/assistant/assistant-panel.tsx` — AI 对话面板 | 替换用户头像占位符 |

### 两个头像系统独立（不能合并）

- **用户头像**（`useUserProfileStore`）：用户个人身份 → O-009 扩展的对象
- **幻灯片解说头像**（`useSkyClassroomStore.selectedAvatarId`）：AI 讲解员角色 → O-009 不碰

## 实施步骤

### Phase 1：基础组件（3 个文件，无依赖）

**文件 1：`components/sky/profile/user-avatar-display.tsx`（新建）**
- 轻量组件，读 `useUserProfileStore` 的 avatar，渲染 `<img>` + 回退 emoji
- Props: `{ size?: 'sm'|'md'|'lg', onClick?: () => void, className?: string }`
- 默认回退：👤
- 替换现有多处硬编码的 👤

**文件 2：`components/sky/profile/avatar-creator.tsx`（新建）**
- 三 Tab 头像创建器：`[预设选择] [上传图片] [AI 生成]`
- **预设 Tab**：网格展示所有 `public/avatars/` 文件 + `AVATAR_OPTIONS`，点击即 `setAvatar()`
- **上传 Tab**：拖拽/选择文件 → FileReader → Canvas 缩放 128x128 → `setAvatar(dataURL)` — 复用 `user-profile.tsx` 的上传逻辑
- **AI 生成 Tab**：文本 prompt 输入 → `POST /api/generate/image` → 预览 → 确认使用（fetch 图片 → canvas → dataURL → `setAvatar`）
- 状态：loading/error/safety-blocked/empty，每种有对应 UI
- 不引入新依赖，纯 React + Tailwind

**文件 3：`app/sky/profile/page.tsx`（新建）**
- 路由 `/sky/profile`，包裹在 `SkyAppShell` 中
- 布局：标题 "个人形象设置" → `AvatarCreator` → 分隔线 → 昵称编辑（行内） → 简介编辑（textarea）
- 昵称/简介编辑直接读写 `useUserProfileStore`
- 遵循天空课堂页面模式：`max-w-2xl` 居中

### Phase 2：全局集成（2 个文件修改）

**文件 4：`components/sky/layout/app-shell.tsx`（修改）**
- 导入 `UserAvatarDisplay`
- 替换顶栏右侧静态 👤 为 `<UserAvatarDisplay size="md" onClick={() => router.push('/sky/profile')} />`
- 点击头像跳转到 `/sky/profile`

**文件 5：`components/sky/assistant/assistant-panel.tsx`（修改）**
- 导入 `useUserProfileStore`
- 替换用户消息气泡中的 👤 为真实头像 `<img>`
- 可选：POST body 附带 nickname/bio，让 AI 助手感知用户

### Phase 3：AI 助手上下文注入（2 个文件修改）

**文件 6：`app/api/sky/assistant/route.ts`（修改）**
- 从请求 body 提取 `nickname`、`bio`（如果客户端发送）
- 传给 `buildSystemPrompt` 的 context 参数

**文件 7：`lib/assistant/context-injector.ts`（修改）**
- `PromptContext` 增加 `nickname?: string` 和 `bio?: string`
- `buildSystemPrompt` 注入：`"当前学生昵称是{name}，简介：{bio}。请用学生名字称呼他们。"`

### Phase 4：导航入口（1 个文件修改，可选）

**文件 8：`components/sky/layout/sky-tab-bar.tsx`（修改）**
- 在 `NAV_ITEMS` 添加：`{ label: '形象', href: '/sky/profile', icon: '👤' }`
- 位置：AI 助手之后

### Phase 5：测试

**文件 9-10：测试文件**
- `tests/sky/profile/avatar-creator.test.tsx` — 三 Tab 渲染/切换、预设点击→setAvatar、AI 生成 mock、错误状态
- `tests/sky/profile/user-avatar-display.test.tsx` — 有头像渲染 img、无头像渲染回退、onClick 触发、size 变体

## 数据流

```
useUserProfileStore（localStorage 持久化 — 唯一数据源）
    │
    ├── UserAvatarDisplay（读 avatar）
    │   ├── SkyAppShell 顶栏         ← 替换 👤
    │   └── AssistantPanel 消息气泡  ← 替换 👤
    │
    ├── AvatarCreator（写 setAvatar）
    │   ├── 预设 Tab → setAvatar(path)
    │   ├── 上传 Tab → setAvatar(dataURL)
    │   └── AI 生成 Tab → POST /api/generate/image → setAvatar(dataURL)
    │
    └── app/sky/profile/page.tsx（读写 nickname/bio/avatar）
```
