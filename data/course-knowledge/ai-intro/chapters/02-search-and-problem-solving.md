# 第 2 章 搜索与问题求解

## 学习目标

- 能够用状态、动作、初始状态、目标测试和代价描述搜索问题。
- 理解 BFS、DFS、一致代价搜索、贪心搜索和 A* 搜索的差异。
- 能够解释启发函数对搜索效率和最优性的影响。

## 核心讲义

搜索是人工智能中最基础的问题求解方法之一。当系统无法一步得到答案时，可以把问题看作从初始状态出发，经过一系列动作，到达目标状态的过程。状态空间由所有可能状态组成，搜索算法负责在这个空间中寻找一条路径。

广度优先搜索（Breadth-First Search, BFS）按层扩展节点，适合边代价相同且需要最短步数解的问题。深度优先搜索（Depth-First Search, DFS）沿一条路径尽可能向深处探索，内存占用较小，但可能陷入很深甚至无限的分支。一致代价搜索（Uniform Cost Search）总是扩展当前路径代价最低的节点，适合边代价不同的问题。

启发式搜索引入启发函数 h(n)，估计从当前节点到目标的代价。贪心最佳优先搜索主要看 h(n)，速度可能快，但不保证最优。A* 搜索综合已付代价 g(n) 和估计剩余代价 h(n)，使用 f(n)=g(n)+h(n) 排序。若 h(n) 从不高估真实代价，A* 在一定条件下可以保证最优。

搜索思想不仅用于迷宫、路径规划和游戏，也用于课程学习路径规划。知识点可以看作状态，学习资源可以看作动作，目标是达到期望掌握度。系统需要在“补基础、学重点、做练习、做项目”之间选择一条合理路径。

## 示例

在“从零学习机器学习基础”的场景中，初始状态是学生掌握 Python 和部分数学基础，目标状态是能解释过拟合并完成 KNN 案例。可行动作包括阅读讲义、观看动画、做诊断题、运行代码案例。路径代价可以综合预计时间和难度，启发函数可以估计某知识点与目标的距离。

## 常见误区

- 把 BFS 和 DFS 只当作代码模板，而忽略它们对状态空间的扩展策略。
- 认为启发函数越复杂越好。启发函数要在信息量和计算成本之间平衡。
- 认为 A* 总是最优。最优性依赖启发函数是否满足条件。
