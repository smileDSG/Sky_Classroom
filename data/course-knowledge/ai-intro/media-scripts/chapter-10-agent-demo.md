# 演示脚本：多智能体生成 RAG 学习资源

## 演示目标

展示多智能体如何根据学生画像和课程知识库协作生成个性化、多模态学习资源，并通过审核 Agent 降低幻觉风险。

## 输入

> 我是软件工程大二学生，正在学人工智能导论。Python 基础还可以，但不太懂过拟合、模型评估和 RAG。希望两周内补上机器学习基础和大模型智能体，偏好代码案例和图解。

## Agent 流程

| 步骤 | Agent | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | Director | 学生自然语言输入 | 任务拆解和执行顺序 |
| 2 | 画像分析 Agent | 学生输入、历史记录 | 8 维学习画像 |
| 3 | 课程理解 Agent | AI 导论知识库 | 相关章节和知识点 |
| 4 | 资源设计 Agent | 画像、知识点、目标 | 资源生成方案 |
| 5 | 讲义 Agent | 第 4、10 章内容 | 个性化讲义 |
| 6 | 题库 Agent | 薄弱知识点 | 分层练习题 |
| 7 | 导图 Agent | 知识图谱 | Mermaid 思维导图 |
| 8 | 案例 Agent | RAG 案例模板 | 代码实操任务 |
| 9 | 视频脚本 Agent | 过拟合/RAG 难点 | 短视频分镜 |
| 10 | 审核 Agent | 生成内容、来源片段 | 置信度、来源、修正建议 |
| 11 | 学习路径 Agent | 审核后资源 | 两周学习路径 |

## 现场展示要点

- Agent 进度要分阶段出现，避免长时间白屏。
- 每个资源卡片展示来源和审核状态。
- 低置信度内容不直接输出为确定事实。
- 最后展示学习路径为什么先补“训练/测试划分”，再学“过拟合”和“RAG”。

## 预期输出资源

1. 个性化讲义：过拟合与 RAG 的图解说明。
2. PPT 大纲：10 页左右，适合复习汇报。
3. 题库：基础题、概念辨析题、案例分析题。
4. 思维导图：机器学习基础 -> 过拟合 -> 评价指标 -> RAG -> 防幻觉。
5. 代码案例：RAG 课程问答助手最小实现。
6. 视频脚本：过拟合诊断 2 分钟讲解。

## 评委提示语

这个演示体现了三件事：第一，系统不是表单，而是从自然语言构建画像；第二，系统不是单模型生成，而是多智能体协作；第三，系统不是无约束生成，而是把课程知识库、来源引用和审核机制放进生成闭环。
